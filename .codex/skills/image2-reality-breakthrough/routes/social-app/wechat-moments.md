# 朋友圈动态 App（虚构：友圈）

## 触发关键词
朋友圈、微信朋友圈、moments、pyq、从朋友圈里出来、朋友圈照片

## 视觉指纹
一部手机屏幕显示着社交动态分享类 App 界面，一条图文动态中的人物身体直接穿过屏幕玻璃，以真实 3D 立体质感探出屏幕平面，另一部分仍留在屏幕内以 2D 平面照片形式存在，界面有头像位、互动图标、评论区占位等社交动态元素，人物仿佛刚从朋友的动态里破壁而出。

## 过渡模板库

### 模板A：俯身探出头 + 水平切面（默认推荐，亲切感强）
- 完全 3D 区域：头部、肩颈、上半身胸腔，人物俯身从屏幕中探出，带着俏皮的笑容，仿佛在跟你打招呼，真实皮肤纹理，自然放松的神态，有明确的体积感和光影层次
- 过渡融合区域：胸腰交界处与屏幕玻璃平面重合处，有界面元素重叠、透明度渐变和轻微的发光边框，仿佛人物正从 UI 界面中浮起；贴附在屏幕表面的头像位、点赞图标、评论气泡等界面元素被人物身体正确遮挡
- 完全 2D 区域：屏幕内的腰以下部分，是社交动态照片中的 2D 平面影像，有手机屏幕的像素感、屏幕反光、轻微色温偏移，呈现明确的平面照片质感，无体积感
- 过渡方式：人物俯身从朋友圈屏幕中探出上半身，屏幕外为 3D 真人，屏幕内为同一人的 2D 社交动态照片，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板B：像素溶解 + 侧身滑出
- 完全 3D 区域：头部、一侧肩、同侧手臂及上半身，以侧面角度从屏幕中滑出，身体呈自然的对角线构图，真实皮肤纹理，自然放松的表情，有明确的体积感和光影层次
- 过渡融合区域：从肩部斜向延伸至髋部的斜线过渡带，人物身体在平面处逐渐溶解为像素粒子又凝聚为真人，像素颗粒沿着身体轮廓飘散，主要分布在身体后方和侧面；贴附在屏幕上的心形点赞和评论气泡被人物身体正确遮挡，少量随像素一起飘散
- 完全 2D 区域：屏幕内的另一侧身体及腰以下部分，是社交动态照片中的 2D 平面影像，有手机屏幕的像素感、屏幕反光、轻微色温偏移，呈现明确的平面照片质感，无体积感
- 过渡方式：人物侧身从朋友圈屏幕中滑出，身体在像素溶解与凝聚中完成 2D→3D 的过渡，以屏幕玻璃为分界面形成破壁错觉

### 模板C：迈步走出全身 + 日常感叙事
- 完全 3D 区域：头部、躯干、双臂及一条腿的大部分，已完全走出屏幕，前脚已经踩在真实的桌面上，重心在前脚，身体微微前倾呈迈步动态，自然的日常穿搭，真实皮肤纹理、服装面料褶皱清晰分明
- 过渡融合区域：另一条腿的小腿处与屏幕平面重合，有像素溶解和粒子飘散效果；贴附在屏幕上的心形点赞图标和评论气泡被人物身体正确遮挡；少量互动图标从人物身后飘散飞出，分布在身体后方和侧面的半空；发梢还拖着淡淡的照片质感残留
- 完全 2D 区域：屏幕内的后脚及鞋履，是社交动态照片中的 2D 平面影像，有手机屏幕的像素感、屏幕反光、轻微色温偏移，呈现明确的平面照片质感，无体积感
- 过渡方式：人物从朋友圈动态中迈步走出，一只脚已踏入现实的桌面，身后飘散着社交互动元素，身上带着照片质感残留，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板D：波动涟漪 + 柔化浮现
- 完全 3D 区域：头部和肩颈，从屏幕中央缓缓浮现，仿佛从水面下升起，真实皮肤纹理，温柔的表情，有明确的体积感和光影层次
- 过渡融合区域：肩颈以下与屏幕平面重合处，屏幕表面像水面一样产生波纹涟漪，界面卡片随波纹扭曲变形，柔化的边缘有梦幻的光晕；贴附在屏幕上的UI元素被人物身体正确遮挡，随波纹一起扭曲
- 完全 2D 区域：屏幕内的躯干及腰以下部分，是社交动态照片中的 2D 平面影像，被波纹扭曲变形，呈现水面倒影般的变形效果，无体积感
- 过渡方式：人物从朋友圈屏幕的涟漪波纹中浮现穿出，屏幕表面呈液面般波动扭曲，以屏幕玻璃为分界面形成柔美的 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质甜美日常，五官清秀自然，带点俏皮的笑容，像在跟你打招呼。

## 默认画幅
9:16 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
手持智能手机（无品牌标识，仅可见手机侧边一小部分）、社交动态类App界面（虚构品牌，与真实品牌无直接关联）
界面元素：用户头像位、昵称占位、发布时间图标、装饰性文字条（抽象色块替代具体文字）、九宫格或单图区域、心形点赞图标、评论气泡图标、底部导航图标
人物身体穿过屏幕平面，俯身或侧身姿势，姿态自然放松
背景：温暖室内，轻微虚化
光影：破壁人物在桌面或掌心投下真实柔和的阴影，增强真实感
