# 邮票

## 触发关键词
邮票、stamp、从邮票里出来、邮票人物、人物邮票

## 视觉指纹
一张放大的邮票贴在信封或集邮册页面上，邮票齿孔内的人物身体正从邮票的微型世界中"放大破壁"而出——身体的一部分仍在邮票齿孔内以微缩 2D 印刷形式存在，另一部分已经放大为真人大小的 3D 立体形态探出邮票平面，大小对比形成强烈的超现实感。

## 过渡模板
- 完全 3D 区域：人物身体的前半部分（头部、肩颈、上半身），真人大小，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，明显在邮票平面之前
- 过渡融合区域：身体穿过邮票齿孔平面的位置，有邮票齿孔边缘、印刷网点、色彩渐变和"放大凝聚"的过渡效果，像素点正在聚合为真实肌肤；贴附在邮票上的面值、国铭等印刷元素被人物身体正确遮挡
- 完全 2D 区域：邮票齿孔内的人物后半部分及背景，是平面印刷的微缩邮票影像，有齿孔边、面值位、国铭位、主题图案（虚构人物主题邮票，不用真实邮票），呈现明确的平面印刷质感，无体积感
- 过渡方式：人物身体从邮票微型世界中"放大破壁"而出，邮票平面之前为真人大小的 3D 形态，邮票之内为微缩的 2D 印刷形态，以邮票齿孔平面为分界面形成尺寸+质感的双重破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质古典优雅，五官精致秀美，表情端庄典雅，像一位古典邮票中的仕女。

## 默认画幅
4:5 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
深色背景或集邮册页面、放大的人物邮票（虚构主题）
邮票元素：齿孔边、面值数字（虚构金额）、国铭（虚构）、主题图案、边纸
桌面道具：放大镜、集邮镊子、其他几枚邮票
光线：柔和的射灯，突出邮票和人物的立体感
人物身体从邮票齿孔中走出，姿态优雅
