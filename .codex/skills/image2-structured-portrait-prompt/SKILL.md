# Image2 结构化人像提示词

## 核心目标

把逐字段输入或自然语言需求整理成稳定的中文人像摄影 Brief，再生成一段覆盖全部字段的 Image2 长提示词。适用于生活照、室内外写真、复古、古风、商业棚拍、时尚 editorial 等多种成年原创人像方向。

## 工作流

1. 读取用户的逐字段输入或自然语言描述，识别并锁定所有安全、明确的值。
2. 将缺失字段围绕同一个视觉主题补全；保证摄影风格、写真方向、场景、服装、气质、动作、光线、滤镜和画幅彼此一致。
3. 读取 `../_shared/core/quality-gates.md`，在涉及年龄、真人、暴露、身体凝视或私密场景时再读取 `../_shared/references/adult-glamour-boundaries.md`。
4. 按“身形方向规则”确定身形描述，按“服装剪裁硬规则”处理服装与补充要求。
5. 先输出固定字段清单，再把所有字段整合为最终中文提示词；最后输出负面限制词和 3–6 个可选变化参数。
6. 默认只返回提示词文本。仅当用户明确说“直接出图”时，才进入图片生成流程；引用图或风格图本身不代表直接出图授权。

## 参数锁定与补全

- 原样保留用户明确给出的安全参数，不用默认值覆盖。
- 用户自定义身形时只使用自定义描述，不加入任何默认身形。
- 用户未指定画幅比例时使用 `9:16`。
- 其他缺失字段按已锁定主题补全，不把下方书店示例当作默认预设。
- 未指定人物身份时，在最终中文提示词中逐字使用主体常量 `原创成年东方女性，20岁及以上`；不要拆分、增字或同义改写。用户指定其他安全成年原创主体时使用其设定。
- 五官保持真实、有辨识度、非网红模板脸；摄影提示词保持真实皮肤、自然比例和合理解剖。
- 若用户输入之间互相矛盾，优先保留更具体的明确值，再调整自动补全部分；不要静默改写无冲突的锁定值。

## 身形方向规则

当用户没有填写身形方向时，每次随机选择且只选择以下一个完整固定描述：

1. `轻盈纤细，上围饱满自然`
2. `成熟丰润完美沙漏型身材，整体呈轻盈纤细美感`

不得同时输出两个默认描述，不得拼接、缩写或同义改写默认描述。用户提供自定义身形时，两个默认描述都不得出现。

## 服装剪裁硬规则

定义不可改写的字面常量：

`REQUIRED_FIT_SENTENCE = 修身剪裁自然突出胸线、腰线和肩颈线`

把 `REQUIRED_FIT_SENTENCE` 的等号右侧内容原样复制到以下两个固定槽位：

- “补充要求”字段以 `强制原句：“修身剪裁自然突出胸线、腰线和肩颈线”。` 结尾。
- “最终中文提示词”服装段落单独写 `服装剪裁要求：“修身剪裁自然突出胸线、腰线和肩颈线”。`

不得在引号内增删字符，不得在“肩颈线”后添加“条”等字，不得用同义句替代。

若用户指定宽松外套、古装、制服或其他非典型修身服装，保留服装类别、颜色、材质和风格，通过内搭、收腰结构、腰封、腰带、合体肩线或层次关系满足该句；不要擅自把服装替换成另一类别。始终以完整人物、服装版型和整体线条为表达语境，不使用胸部局部特写、低机位身体凝视或露骨描述。

## 固定输出契约

所有用户可见内容使用简体中文。把下面的 `FIELD_LABELS` 视为不可改写的字面数组：

`FIELD_LABELS = [摄影风格, 写真方向, 场景方向, 服装方向, 气质标签, 五官方向, 五官细节, 发型方向, 身形方向, 线条强调, 镜头方向, 姿态动作, 光线氛围, 滤镜效果, 画幅比例, 补充要求]`

逐项复制 `FIELD_LABELS` 中的标签，只填写中文冒号后的值。严格按下列顺序输出，不从记忆重写字段名，不省略字段，不插入其他字段：

```text
摄影风格：...
写真方向：...
场景方向：...
服装方向：...
气质标签：...
五官方向：...
五官细节：...
发型方向：...
身形方向：...
线条强调：...
镜头方向：...
姿态动作：...
光线氛围：...
滤镜效果：...
画幅比例：...
补充要求：...。强制原句：“修身剪裁自然突出胸线、腰线和肩颈线”。

最终中文提示词：
...

负面限制词：
...

可选变化参数：
- ...
- ...
- ...
```

最终中文提示词必须覆盖 16 个字段的全部有效信息，并以独立句逐字包含 `REQUIRED_FIT_SENTENCE` 的内容。负面限制词应简洁且与任务相关，通常覆盖：未成年感、学生元素、真实人物相似、网红模板脸、身体局部特写、低机位身体凝视、露骨表达、过度磨皮、塑料皮肤、解剖错误、手指畸形、水印、乱码文字。可选变化参数只改变色调、镜头、材质、场景细节、姿态或画幅，不得改写锁定参数。

## 质量检查

输出前逐项确认：

- 16 个字段名称、数量和顺序完全一致。
- 将输出字段名与 `FIELD_LABELS` 逐项精确比较；若出现已知近似错误 `写实方向` 或 `拍摄方向`，替换为 `写真方向`，其他不一致标签也必须按数组修正后再返回。
- 身形缺失时只出现一个固定默认值；身形自定义时不出现默认值。
- 对“补充要求”和“最终中文提示词”分别执行精确子串检查：必须包含 `修身剪裁自然突出胸线、腰线和肩颈线`。若发现近似错误 `修身剪裁自然突出胸线、腰线和肩颈线条`，必须把它替换为正确原句；缺少或发生其他改写时，也先替换为原句再返回。
- 长提示词明确是原创成年人物，并覆盖全部已锁定参数和补全字段。
- 画面表现为整体人像摄影，不把胸、腰、臀或其他身体局部作为独立焦点。
- 场景、动作、镜头与光线在现实中能够同时成立；无未授权真人相似、幼态、偷拍、露骨或非自愿语境。

## 完整示例：冷白 CCD 书店生活照

```text
摄影风格：冷白清透CCD生活照风
写真方向：知性室内生活照
场景方向：现代书店阅读区 / 白色书架 / 浅木桌 / 大面积落地窗
服装方向：湖蓝色修身针织上衣 + 米白色高腰包臀中裙
气质标签：知性、清冷、安静、温柔、干净
五官方向：真实清冷淡颜，干净高级，不网红
五官细节：偏窄鹅蛋脸，轮廓利落但柔和；清亮杏眼，眼神安静克制；鼻梁清秀流畅；唇形自然克制，低饱和裸粉唇色
发型方向：黑色长发低扎或自然披散，脸侧少量碎发，整体利落干净
身形方向：轻盈纤细，上围饱满自然
线条强调：中偏强
镜头方向：半身到大腿
姿态动作：站在书架旁，弯着腰查找书籍
光线氛围：落地窗高色温自然光 + 书架白色漫反射 + 冷白极弱柔闪
滤镜效果：冷白高光 + 蓝白清透CCD色彩 + 轻颗粒 + 轻数码噪点
画幅比例：9:16
补充要求：湖蓝色上衣要清爽高级，整体知性但不沉闷。强制原句：“修身剪裁自然突出胸线、腰线和肩颈线”。

最终中文提示词：
9:16 竖幅冷白清透 CCD 生活摄影，一位原创成年东方女性，20岁及以上，轻盈纤细、上围饱满自然，站在现代书店阅读区的白色书架旁，弯腰安静查找书籍；浅木桌、大面积落地窗与整洁书脊构成真实生活背景。她拥有真实清冷淡颜与偏窄鹅蛋脸，轮廓利落但柔和，清亮杏眼、安静克制的眼神、清秀流畅的鼻梁、自然克制的唇形和低饱和裸粉唇色，不呈现网红模板脸。黑色长发低扎或自然披散，脸侧保留少量碎发。身穿清爽高级的湖蓝色修身针织上衣和米白色高腰包臀中裙，以完整服装版型和整体人物线条呈现中偏强的线条强调，知性但不沉闷。服装剪裁要求：“修身剪裁自然突出胸线、腰线和肩颈线”。半身到大腿构图，平视自然视角，落地窗高色温自然光、书架白色漫反射与冷白极弱柔闪共同照明，冷白高光、蓝白清透 CCD 色彩、轻颗粒和轻数码噪点，真实皮肤纹理，安静、温柔、干净的书店生活抓拍感。

负面限制词：
未成年感、学生元素、真实人物相似、网红模板脸、身体局部特写、低机位身体凝视、露骨表达、过度磨皮、塑料皮肤、解剖错误、手指畸形、水印、乱码文字

可选变化参数：
- 发型改为利落低马尾
- 镜头改为 50mm 平视三分之四身
- CCD 颗粒强度轻微增加
```

示例仅说明输出结构和完成度。处理其他主题时，根据用户输入重新生成全部字段，不复用书店、湖蓝服装或冷白 CCD 内容。
