# 手机屏幕

## 触发关键词
手机里、手机屏幕、从手机里出来、phone screen、手机屏、从手机里走出来、手机相册

## 视觉指纹
一部黑色智能手机亮着屏幕，显示一张人物照片，照片中的人物身体直接穿过屏幕玻璃，上半身以真实 3D 立体质感探出屏幕平面进入现实空间，下半身仍留在屏幕内以 2D 平面照片形式存在，屏幕边缘有轻微的发光和像素扩散效果，形成"从手机里出来"的超现实错觉。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身胸腔及一只手臂，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，肩膀和手臂明显高出屏幕玻璃平面
- 过渡融合区域：胸腰交界处与屏幕玻璃平面重合处，有像素化扩散、屏幕辉光和色彩溢出效果，仿佛人物正穿过像素矩阵
- 完全 2D 区域：屏幕内的腰以下及腿部，是手机照片中的 2D 平面影像，有手机屏幕的像素网格、反光和色彩偏移，呈现明确的平面照片质感，无体积感
- 过渡方式：人物身体直接穿过手机屏幕玻璃平面，屏幕外为 3D 真人，屏幕内为同一人的 2D 照片影像，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，皮肤白皙自然，五官精致，气质甜美灵动，眼神惊喜好奇，仿佛刚从手机世界里发现了出口。

## 默认画幅
9:16 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
黑色智能手机立放在桌面上（无品牌标识）、屏幕亮着、显示相册照片界面、屏幕有轻微反光和指纹
人物身体穿过屏幕平面，上半身探出，一只手臂自然伸向画面外
背景：温暖的室内环境，柔和的桌面灯光，轻微景深虚化
手机界面元素：状态栏图标、时间数字位、电量图标、相册标题位（抽象文字条）
