# CD/磁带封面

## 触发关键词
CD封面、磁带、cd cover、cassette、唱片封面、从CD里出来、专辑封面

## 视觉指纹
一张CD唱片（或磁带）放在桌面上，封面的人像从CD盒中立体浮出来，上半身突破平面，CD的反光、塑料盒光泽和印刷网点在过渡区域清晰可见，旁边散落着歌词本和耳机。

## 过渡模板
- 完全写实区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理，人物从CD封面中"站出来"
- 过渡融合区域：腰腹部到CD表面，有印刷网点渐变、塑料盒反光、镭射光效果，仿佛人物正从塑料包装里出来
- 纯媒介区域：CD封面下半部分，是平面印刷效果，有专辑名（虚构）、艺人名字（虚构）、曲目列表、条形码、印刷网点
- 过渡方式：从CD/磁带封面中"走出来"，上半身真人立体，下半身还在封面印刷里，塑料盒的透明壳和反光增加真实感

## 默认主体气质
原创成年东方女性，20岁及以上，气质歌手明星范，五官精致上镜，表情自信有舞台感，像一个新晋歌手的首张专辑。

## 默认画幅
1:1 正方形构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
木质桌面 / 深色背景、CD塑料盒 + 封面（虚构专辑名，如「城市漫游」「时光单曲」）
封面元素：虚构专辑名、虚构艺人名、曲目列表、唱片公司名（虚构）、条形码、印刷网点
桌面道具：耳机、歌词本、磁带几盒、唱片播放机一角
光线：柔和的侧光，CD塑料有反光和镭射效果
人物一只手搭在CD盒边缘，上半身挺起
