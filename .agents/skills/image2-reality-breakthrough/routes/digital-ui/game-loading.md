# 游戏加载界面

## 触发关键词
游戏加载、loading screen、游戏界面、加载画面、从游戏里出来、loading

## 视觉指纹
一个游戏加载界面在屏幕上显示，加载画面中的人物身体直接穿过游戏界面平面，上半身以真实 3D 立体质感从游戏里走出来，下半身仍留在加载界面内以 2D 游戏立绘形式存在，进度条、技能图标、loading 装饰元素在过渡区域闪烁，角色像是从加载界面中"加载完成"来到现实。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，角色从加载画面中"具现化"，明显在屏幕平面之前
- 过渡融合区域：腰胯部与屏幕平面重合处，有像素化渐变、加载进度条增长、技能图标点亮、粒子特效的效果；贴附在界面上的loading标识、技能图标、游戏logo等UI元素被人物身体正确遮挡；少量粒子从过渡区域飘散，主要在人物身后和侧面
- 完全 2D 区域：加载界面和游戏UI中的下半身，是 2D 平面游戏风格，有 loading 标识、进度条、角色头像位、技能图标、游戏 logo（虚构）、小贴士，呈现明确的平面游戏 UI 质感，无体积感
- 过渡方式：人物身体直接穿过游戏加载界面平面，界面之前为 3D 高保真真人，界面之内为同一人的 2D 游戏立绘，以屏幕平面为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质游戏飒爽，五官锐利立体，表情冷静酷帅，像一个RPG游戏的女主角。

## 默认画幅
16:9 横版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
电脑屏幕 / 游戏主机画面、游戏加载界面（虚构游戏名）
游戏UI元素：loading标识、进度条、角色头像位、技能图标、虚构游戏logo、小贴士、版本号
环境道具：游戏手柄、RGB键盘、耳机、显示器发光
光线：屏幕冷光 + RGB幻彩，游戏氛围十足
人物从加载界面中走出来
