# 种草笔记 App（虚构：小红本）

## 触发关键词
小红书、xiaohongshu、red note、小红薯、从小红书里出来、种草图、笔记配图、穿搭笔记

## 视觉指纹
一部手机屏幕显示着种草笔记类 App 界面，笔记封面图中的人物身体直接穿过屏幕玻璃，以真实 3D 立体质感探出屏幕平面，另一部分仍留在屏幕内以 2D 平面图片形式存在，界面有卡片式布局、标签图标和互动按钮等元素，人物仿佛刚从爆款笔记里"活"过来破壁而出。

## 过渡模板库

### 模板A：伸手向前 + 像素溶解（默认推荐，互动感强）
- 完全 3D 区域：一只手和前臂完全伸出屏幕，手指伸向观众方向，仿佛在递出一件种草好物，手部有真实皮肤纹理、指甲细节和体积感，是画面的视觉焦点
- 过渡融合区域：手腕和前臂中部与屏幕玻璃平面重合处，有图片卡片边框发光、滤镜色彩溢出和像素溶解效果，仿佛手正从平面图片中凝聚成形；贴附在屏幕表面的心形点赞、星形收藏等小图标被人物手臂正确遮挡；少量细小图标从过渡区域向四周飘散，主要分布在手臂后方和侧面
- 完全 2D 区域：屏幕内的身体其余部分（头部、躯干、另一条手臂、双腿），是笔记封面图中的 2D 平面影像，有手机屏幕的像素网格感、屏幕反光、轻微色彩偏移，呈现明确的平面图片质感，无体积感
- 过渡方式：人物的一只手臂穿过种草笔记 App 屏幕伸向观众，手和前臂为 3D 真人质感，身体其余部分仍在屏幕内为 2D 笔记封面影像，以屏幕玻璃为分界面形成强烈的 2D→3D 破壁错觉

### 模板B：俯身探出头 + 斜向切面
- 完全 3D 区域：头部、一侧肩颈、上半身胸腔及同侧手臂，人物俯身从屏幕中探出，仿佛在分享好物，真实皮肤纹理和精致妆容，有明确的体积感和光影层次，明显高出屏幕玻璃平面
- 过渡融合区域：从一侧肩部斜向延伸至对侧腰部的斜线切面与屏幕平面重合处，有图片卡片边框发光、滤镜色彩溢出效果；贴附在屏幕表面的心形和星形互动图标、标签等界面元素被人物身体正确遮挡；少量细小图标从过渡区域飘散，主要在人物身后
- 完全 2D 区域：屏幕内的另一侧身体及腰以下腿部，是笔记封面图中的 2D 平面影像，有手机屏幕的像素网格感、屏幕反光、轻微色彩偏移，呈现明确的平面图片质感，无体积感
- 过渡方式：人物俯身从种草笔记屏幕中斜向探出上半身，屏幕外为 3D 真人，屏幕内为同一人的 2D 笔记封面影像，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板C：迈步走出全身 + 界面元素飘散
- 完全 3D 区域：头部、躯干、双臂及一条腿的大部分，已完全走出屏幕，前脚已经踩在真实的咖啡馆桌面上，重心在前脚，身体微微前倾呈迈步动态，手中拎着一只从界面幻化出来的购物袋（购物袋自然挡在身前，有真实体积感），真实皮肤纹理、服装面料褶皱清晰分明
- 过渡融合区域：另一条腿的小腿处与屏幕平面重合，有像素溶解和粒子飘散效果；贴附在屏幕上的心形点赞图标、星形收藏图标、评论气泡等互动元素被人物身体正确遮挡；少量互动图标从人物身后飘散飞出，分布在身体后方和侧面的半空；发梢和裙摆还拖着淡淡的滤镜色彩残留
- 完全 2D 区域：屏幕内的后脚及鞋履，是笔记封面图中的 2D 平面影像，有手机屏幕的像素网格感和屏幕反光，呈现明确的平面图片质感，无体积感
- 过渡方式：博主从种草笔记 App 中迈步走出，一只脚已踏入现实的咖啡馆桌面，身后飘散着互动图标，身上带着滤镜色彩残留，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板D：波动涟漪 + 侧身滑出
- 完全 3D 区域：头部、一侧肩、同侧手臂及上半身，以侧面角度从屏幕中滑出，身体呈优雅的对角线构图，真实皮肤纹理和精致妆容，有明确的体积感和光影层次
- 过渡融合区域：从肩到髋的斜线过渡带，屏幕表面像水面一样产生波纹涟漪，人物从波纹中央浮现穿出，界面卡片随波纹扭曲变形，柔化的边缘有梦幻的滤镜色彩溢出；贴附在屏幕上的UI元素被人物身体正确遮挡，随波纹一起扭曲
- 完全 2D 区域：屏幕内的另一侧身体及腰以下腿部，是笔记封面图中的 2D 平面影像，被波纹扭曲变形，呈现水面倒影般的变形效果，无体积感
- 过渡方式：人物侧身从种草笔记屏幕的涟漪波纹中浮现穿出，屏幕表面呈液面般波动扭曲，以屏幕玻璃为分界面形成柔美的 2D→3D 破壁错觉

### 模板E：反向破壁 — 滤镜色彩吸入式
- 完全 3D 区域：头部、肩颈、上半身及一只伸向现实的手臂，完全立体写实，真实皮肤纹理和精致妆容，表情惊讶不舍，手指试图抓住桌面上的咖啡杯，头发和衣物向手机屏幕方向飘动
- 过渡融合区域：胸腰交界处被手机屏幕吸入，屏幕边缘有向内汇聚的滤镜色彩漩涡；贴附在屏幕上的心形和星形图标被倒流回屏幕，有被吸入的运动感；发梢开始被像素化和滤镜染色，指尖已经开始变成平面笔记封面质感
- 完全 2D 区域：屏幕内的腰以下及腿部，已被完全吸入手机，呈现笔记封面图中的 2D 平面影像，有屏幕像素网格和滤镜色彩，呈现明确的平面图片质感，无体积感
- 过渡方式：现实博主正在被吸入种草笔记 App 屏幕，身体 3D→2D 反向过渡，屏幕边缘有滤镜色彩漩涡，人物挣扎中部分身体已变成 2D 笔记封面影像

## 默认主体气质
原创成年东方女性，20岁及以上，气质精致时尚，妆容干净高级，表情甜美自信，像一个刚分享完穿搭笔记的博主。

## 默认画幅
3:4 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

智能手机（无品牌标识）立放在桌面上、种草笔记类App界面（虚构品牌，与真实品牌无直接关联）
界面元素：瀑布流卡片布局、封面图、装饰性色块和图形（替代文字标题）、几何标签图标、心形和星形互动按钮、用户头像位、底部导航图标
