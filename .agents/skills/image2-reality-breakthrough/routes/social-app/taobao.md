# 电商详情页 App（虚构：淘购）

## 触发关键词
淘宝、taobao、详情页、商品页、宝贝详情、从淘宝里出来、模特图、主图视频

## 视觉指纹
一部手机屏幕显示着电商商品详情类 App 界面，一张主图中的服装模特身体直接穿过屏幕玻璃，以真实 3D 立体质感探出屏幕平面，另一部分仍留在屏幕内以 2D 商品主图形式存在，界面有主图轮播、价格标签、规格选择、购物按钮等电商元素，人物像是从商品详情页里"活"了过来。

## 过渡模板库

### 模板A：迈步走出全身 + 斜向切面（默认推荐，全身有叙事）
- 完全 3D 区域：头部、躯干、双臂及一条腿的大部分，已完全走出屏幕，前脚已经踩在真实的展示台上，重心在前脚，身体微微前倾呈迈步动态，真实皮肤纹理、服装面料褶皱、纽扣缝线清晰分明，有明确的体积感和光影层次
- 过渡融合区域：从一侧大腿斜向延伸至对侧小腿的斜线切面与屏幕平面重合，有商品图片白边发光效果；贴附在屏幕上的价格标签、购物车图标、主图轮播圆点等UI元素被人物身体正确遮挡；少量电商图标从人物身后飘散飞出，分布在身体后方和侧面的半空；裙摆和发梢还带着淡淡的屏幕像素残留
- 完全 2D 区域：屏幕内的另一条腿的下半部分及鞋履，是电商主图中的 2D 平面影像，有商品图片的棚拍质感、屏幕像素感、轻微锐化感，呈现明确的平面图片质感，无体积感
- 过渡方式：人物迈步从电商详情页手机屏幕中走出，一只脚已踏入现实，另一只脚还在屏幕内，身上带着屏幕像素残留和飘散的电商UI元素，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板B：玻璃碎裂飞溅 + 仰身冲出
- 完全 3D 区域：头部、肩颈、上半身及双臂，完全立体写实，真实皮肤纹理和服装面料质感，头发和衣物向后飞扬有动感，双臂微张仿佛刚冲破屏障，有明确的体积感和光影层次
- 过渡融合区域：胸肩区域周围的屏幕玻璃呈放射状碎裂，多块大小不一的玻璃碎片飞溅悬浮在空中，主要分布在人物身后和身体两侧；贴附在屏幕上的价格标签、优惠券、五星评价图标等电商元素被人物身体正确遮挡，部分从碎片间隙中可见；极少数细小碎片飞近镜头形成前景虚化效果，不遮挡面部
- 完全 2D 区域：屏幕内的腰以下及腿部，是电商主图中的 2D 平面影像，透过未碎裂的屏幕区域可见，有商品图片的棚拍质感和屏幕像素感，呈现明确的平面图片质感，无体积感
- 过渡方式：人物冲破手机屏幕玻璃，玻璃呈放射状碎裂飞溅，人物从碎裂缺口中冲出，屏幕外为 3D 真人，屏幕内为同一人的 2D 电商主图

### 模板C：俯身探出头 + 水平切面
- 完全 3D 区域：头部、肩颈、上半身胸腔，人物俯身从屏幕中探出，仿佛在展示身上的服装，真实皮肤纹理和服装面料质感，有明确的体积感和光影层次，明显高出屏幕玻璃平面
- 过渡融合区域：胸腰交界处与屏幕玻璃平面重合处，有商品图片白边发光效果；贴附在屏幕表面的价格标签图标、主图轮播圆点等UI元素被人物身体正确遮挡；少量细小图标从过渡区域飘散，主要在人物身后
- 完全 2D 区域：屏幕内的腰以下及腿部，是电商主图中的 2D 平面影像，有商品图片的棚拍质感、屏幕像素感、轻微锐化感，呈现明确的平面图片质感，无体积感
- 过渡方式：人物身体直接穿过手机屏幕玻璃平面，屏幕外为 3D 真人，屏幕内为同一人的 2D 电商主图，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板D：像素溶解 + 侧身滑出
- 完全 3D 区域：头部、一侧肩、同侧手臂及上半身，以侧面角度从屏幕中滑出，身体呈对角线构图，真实皮肤纹理和服装面料质感，有明确的体积感和光影层次
- 过渡融合区域：从肩部斜向延伸至髋部的斜线过渡带，人物身体在平面处逐渐溶解为像素粒子又凝聚为真人，像素颗粒沿着身体轮廓飘散，主要分布在身体后方和侧面；贴附在屏幕上的电商图标被人物身体正确遮挡，少量随粒子一起飘散
- 完全 2D 区域：屏幕内的另一侧身体及腰以下腿部，是电商主图中的 2D 平面影像，有屏幕像素感和轻微的色彩偏移，呈现明确的平面图片质感，无体积感
- 过渡方式：人物侧身从电商详情页屏幕中滑出，身体在像素溶解与凝聚中完成 2D→3D 的过渡，以屏幕玻璃为分界面形成破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质清新甜美，五官端正，表情自然专业，像一个服装电商的签约模特。

## 默认画幅
9:16 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
智能手机（无品牌标识）、电商详情页类App界面（虚构品牌，与真实品牌无直接关联）
界面元素：主图轮播区、标题文字条（抽象色块）、价格标签图标、划线原价位、销量数字占位、店铺名称位、立即购买/加入购物车按钮、颜色/尺码选择图标、评价星级图标
人物身体穿过屏幕平面，采用迈步走出或俯身姿势，展示服装的姿态
光线：明亮干净的电商棚拍光线，简约背景
光影：破壁人物在台面投下真实的阴影，增强破壁的立体感和真实感
创意道具：飞出的购物袋、飘散的优惠券和红包元素（全身破壁场景）
