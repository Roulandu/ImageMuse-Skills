# 油画

## 触发关键词
油画、oil painting、从油画里出来、油画人物、画布人物

## 视觉指纹
一幅装在华丽画框里的油画挂在墙上，画布中的人物身体直接穿过画布平面，以真实 3D 立体质感从油画布里走出来，另一部分仍留在画布内以 2D 油画笔触形式存在，颜料的肌理感和厚重感在过渡区域清晰可见，真实的展厅光线照在人物和画框上。

## 过渡模板库

### 模板A：颜料肌理渐变 + 俯身探出头（默认推荐）
- 完全 3D 区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，人物从画布中探出，明显在画框平面之前
- 过渡融合区域：腰胯部与画布平面重合处，有油画颜料肌理渐变、厚涂笔触融入、色彩层叠的效果，仿佛颜料正在变成真实肌肤
- 完全 2D 区域：画面下半部分及腿部，是纯油画效果，有明显的画笔笔触、颜料肌理、调色刀痕迹、画框边缘，呈现明确的平面绘画质感，无体积感
- 过渡方式：人物身体直接穿过油画布面平面，画布之前为 3D 真人，画布之内为同一人的 2D 油画人像，以画布平面为分界面形成 2D→3D 破壁错觉

### 模板B：画布撕裂 + 迈步走出
- 完全 3D 区域：头部、躯干、双臂及一条腿的大部分，已完全走出画布，前脚踩在真实的木地板上，重心在前脚，身体微微前倾呈迈步动态，真实皮肤纹理、服装面料褶皱清晰分明
- 过渡融合区域：另一条腿的小腿处与画布平面重合，画布被撕开一道不规则裂口，边缘有纤维毛边和翻卷，厚涂油画颜料在撕裂处被拉伸变形，人物从裂口中走出
- 完全 2D 区域：画布内的后脚及鞋履，是纯油画效果，有明显的画笔笔触和颜料肌理，呈现明确的平面绘画质感，无体积感
- 过渡方式：人物从油画布的撕裂缺口中迈步走出，画布之前为 3D 真人，画布之内为同一人的 2D 油画，以画布平面为分界面形成 2D→3D 破壁错觉

### 模板C：笔触溶解 + 侧身滑出
- 完全 3D 区域：头部、一侧肩、同侧手臂及上半身，以侧面角度从画布中滑出，身体呈优雅的对角线构图，真实皮肤纹理，古典优雅的气质，有明确的体积感和光影层次
- 过渡融合区域：从肩部斜向延伸至髋部的斜线过渡带，油画笔触在过渡处逐渐溶解为颜料颗粒又凝聚为真人皮肤，调色刀痕迹沿身体轮廓延伸，颜料颗粒在空中飘散
- 完全 2D 区域：画布内的另一侧身体及腿部，是纯油画效果，有明显的画笔笔触和颜料肌理，呈现明确的平面绘画质感，无体积感
- 过渡方式：人物侧身从油画布中滑出，身体在笔触溶解与凝聚中完成 2D→3D 的过渡，以画布平面为分界面形成破壁错觉

### 模板D：反向破壁 — 颜料吸入式
- 完全 3D 区域：头部、肩颈、上半身及一只伸向画框外的手臂，完全立体写实，真实皮肤纹理，表情沉静迷离，手指试图抓住画框边缘，头发和衣物向画布方向飘动
- 过渡融合区域：腰胯部正在被画布吸入，画面边缘有向内汇聚的颜料漩涡、笔触逆流回画布，指尖开始变成油画颜料的厚涂质感，衣角被拖入画布平面变成笔触纹理
- 完全 2D 区域：画布内的下半身及腿部，已被完全吸入画布，呈现纯油画效果，有明显的画笔笔触、颜料肌理、调色刀痕迹，呈现明确的平面绘画质感，无体积感
- 过渡方式：现实人物正在被吸入油画布中，身体 3D→2D 反向过渡，画布边缘有颜料漩涡，人物挣扎中部分身体已变成油画笔触

## 默认主体气质
原创成年东方女性，20岁及以上，气质古典优雅，五官立体深邃，眼神沉静神秘，像一幅古典名画中的人物。

## 默认画幅
3:4 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
美术馆或私人展厅墙面、华丽金框油画（虚构画作）
油画元素：厚重油彩肌理、画笔笔触、调色刀痕迹、古典画风、画框雕花
环境道具：木地板、展厅射灯、旁边另一幅画的边缘、长椅一角
光线：展厅顶光射灯，画框有高光，人物有真实光影
人物身体穿过画布平面，微微向前探出（正向）或被吸入（反向）
光影：破壁人物在木地板和画框上投下真实的阴影，增强真实感
