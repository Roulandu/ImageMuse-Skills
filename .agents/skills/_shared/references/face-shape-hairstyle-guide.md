# 发型 × 脸型搭配指南

## 使用说明

本指南供 Skill 在推荐发型或修复发型问题时参考。
仅在用户明确提到脸型、或需要根据脸型优化发型时使用。
不默认添加到 prompt 中——只作为选择/推荐的依据。

## 脸型分类与发型搭配

### 鹅蛋脸
- **脸型特点**：脸型柔和流畅，额头自然饱满，下颌线圆润收束但不过分尖锐，面部骨相温润端正。
- **修饰方向**：几乎所有发型都适合，重点在于突出气质
- **推荐预设**：
  1. 直长发 — 顺滑垂坠，凸显面部温润比例与清冷高级气质
  2. 长波波头 — 锁骨长度微卷带层次，温柔知性，尽显好比例
  3. 高马尾 — 露额露颈，突出干净五官与明艳大方气场
  4. 低盘发 — 优雅端庄，让柔和鹅蛋脸更显贵气与精致
  5. 温柔大卷 — 侧分八字刘海+蓬松大卷，浪漫妩媚女人味拉满
  6. 港风侧分大卷 — 蓬松浓密大波浪一侧垂肩，复古明艳大气场
  7. 锁骨内扣 — 齐锁骨发尾内扣，干练都市，利落中带温婉
- **避雷**：几乎无雷区

### 圆脸
- **脸型特点**：脸部轮廓饱满流畅，苹果肌自然丰润，下颌线柔和模糊，整体亲切温柔。
- **修饰方向**：拉长脸型、增加头顶高度、两侧收紧、增加纵向线条
- **推荐预设**：
  1. 直长发 — 中分露额顺直垂坠，纵向拉长脸型，显脸小
  2. 长波波头 — 侧分刘海+锁骨微卷层次，修饰圆润轮廓
  3. 高马尾 — 头顶高位扎起，拉高颅顶，纵向延伸脸型
  4. 八字刘海中长发 — 两侧刘海柔和颧骨，蓬松微卷显瘦
- **避雷预设**：
  1. 公主切 — 脸颊两侧刀切齐整直发，横向切割脸线，显脸更圆
  2. 低马尾 — 颈后低位扎起，两侧贴服，凸显圆润轮廓
  3. 齐刘海长发 — 一刀齐整刘海盖眉，缩短脸型，显脸更圆

### 方圆脸
- **脸型特点**：面部轮廓端正饱满，下颌骨存在感自然但不过分棱角化，脸颊线条圆润，骨相稳定耐看。
- **修饰方向**：柔化下颚线条、增加柔和曲线、侧分避免正对称
- **推荐预设**：
  1. 直长发 — 中分顺直垂坠，柔化方正下颌，纵向延伸轮廓
  2. 低马尾 — 侧分发丝服帖顺滑，耳前碎发柔和方下颌
  3. 半扎发 — 上扎下披发尾微卷，分散对方下颌的注意力
  4. 八字刘海中长发 — 两侧刘海柔和颧骨与下颌方正感
  5. 温柔大卷 — 侧分八字刘海+蓬松大卷，曲线柔化方正线条
- **避雷预设**：
  1. 波波头 — 齐下巴短波波+内扣，结束位置正好突出方下颌
  2. 精灵短发 — 耳上长度露额露颌，完全暴露方正下颌线条
  3. 公主切 — 脸颊刀切齐整直发，强化方正感与棱角感

### 长脸
- **脸型特点**：面部纵向比例略长，额头自然舒展，脸颊线条干净，整体修长清冷。
- **修饰方向**：增加横向宽度、齐刘海缩短脸长、蓬松两侧
- **推荐预设**：
  1. 长波波头 — 锁骨长度微卷层次，横向拉宽视觉，缩短脸长
  2. 公主切 — 齐刘海+脸颊刀切直发，有效缩短脸长比例
  3. 低马尾 — 颈后低位扎起，弱化纵向延伸感，更平衡
  4. 齐刘海长发 — 一刀齐刘海盖眉，直接缩短上庭，平衡长脸
  5. 海浪卷 — 蓬松大波浪增加横向宽度，中和纵向修长感
- **避雷预设**：
  1. 直长发 — 中分顺直垂腰，纵向拉长效果明显，脸显得更长
  2. 高马尾 — 头顶高位扎起露额，进一步拉长纵向比例
  3. 半扎发 — 上扎下披，头顶蓬松加高，加长脸长

### 心形脸
- **脸型特点**：额头略微饱满，太阳穴线条顺滑，脸部下半段逐渐收窄，下巴小巧圆润。
- **修饰方向**：平衡上宽下窄、下颚蓬松饱满、侧分柔和额角
- **推荐预设**：
  1. 波波头 — 齐下巴短波波+内扣，增加下颌两侧饱满度
  2. 精灵短发 — 耳上长度露额，凸显精致下巴与上庭优势
  3. 高马尾 — 露额露颈，突出心形脸的灵动与精致感
  4. 丸子头 — 头顶盘发，重心上移，让尖下巴更显俏皮
  5. 花环编发 — 头顶花环式编发，平衡上宽下窄的视觉差
- **避雷预设**：
  1. 直长发 — 中分贴头皮直长发，强化上宽下窄，显下巴更尖
  2. 湿发造型 — 后梳露额+贴服发丝，凸显宽额头与尖下巴

### 菱形脸
- **脸型特点**：颧骨位置略有骨相支撑，额头宽度适中，下颌逐渐收束，整体高级冷感。
- **修饰方向**：柔和颧骨线条、增加额头和下颚饱满度、侧分刘海
- **推荐预设**：
  1. 波波头 — 齐下巴短波波+侧分内扣，柔和颧骨与尖下巴
  2. 精灵短发 — 顶部蓬松层次，增加额头饱满度，平衡颧骨
  3. 鱼骨辫 — 侧分单边鱼骨辫，不对称线条柔化颧骨棱角
  4. 花环编发 — 头顶花环式编发，增加上庭宽度，柔化颧骨
  5. 温柔大卷 — 侧分八字刘海+蓬松大卷，曲线包裹颧骨
- **避雷预设**：
  1. 狼尾层次剪 — 顶部短层次+轻薄发尾，凸显颧骨宽与下巴尖
  2. 湿发造型 — 后梳露额+贴服发丝，完全暴露颧骨棱角
  3. 直长发 — 中分顺直垂坠，两侧贴服，凸显颧骨外扩感
