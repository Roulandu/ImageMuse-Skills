# 参数映射与占位符系统

## 占位符定义

提示词中使用 [[占位符]] 标记可替换参数。所有占位符在子模板文件中使用，在最终提示词组装时替换为实际值。

| 占位符 | 类型 | 说明 | 来源优先级（高→低） |
|--------|------|------|-------------------|
| [[face]] | 面部特征 | 脸型、五官风格、气质 | 用户输入 > 参考图提取 > 子模板默认 |
| [[hairstyle]] | 发型 | 发型类型、长度 | 用户输入 > 参考图提取 > 知识库匹配 > 子模板默认 |
| [[haircolor]] | 发色 | 发色描述 | 用户输入 > 参考图提取 > 子模板默认 |
| [[eyecolor]] | 瞳色 | 瞳色描述 | 用户输入 > 参考图提取 > 子模板默认 |
| [[outfit-color]] | 服装主色调 | 服装配色方案 | 用户输入 > 参考图提取 > 子模板默认 |
| [[outfit-material]] | 服装面料 | 材质描述 | 用户输入 > 参考图提取 > 子模板默认 |
| [[scene-detail]] | 场景细节 | 环境具体描述 | 用户输入 > 参考图提取 > 子模板默认 |
| [[prop]] | 道具 | 手持/配饰道具 | 用户输入 > 参考图提取 > 子模板默认 |
| [[light-mood]] | 光线氛围 | 光线情绪形容词 | 用户输入 > 参考图提取 > 子模板默认 |
| [[body-type]] | 身形 | 身形描述 | 用户输入 > 子模板默认（不通过参考图提取） |

## 默认值

当占位符未被用户输入或参考图覆盖时，使用子模板中定义的默认值。子模板默认值在该子模板文件的对应字段中定义。

## 参考图映射规则

### 特征提取维度

| 维度 | 提取目标 | 映射到占位符 | 默认启用 |
|------|---------|-------------|---------|
| 面部特征 | 脸型、五官风格、气质关键词 | [[face]] | 是 |
| 发型发色 | 发型类型、长度、颜色 | [[hairstyle]] + [[haircolor]] | 是 |
| 服装造型 | 服装类型、配色、材质、层次 | [[outfit-color]] + [[outfit-material]] | 是 |
| 道具配饰 | 标志性物品 | [[prop]] | 是 |
| 整体色调 | 主色调、氛围色 | 注入光影/场景描述 | 是 |

### 映射优先级

```
用户显式输入 > 参考图提取 > 子模板默认值
```

### 用户限定指令

用户可用以下限定指令控制参考图用途：
- "只参考服装" — 仅提取服装维度的特征
- "只参考面部" — 仅提取面部特征
- "只参考发型" — 仅提取发型发色
- "只参考道具" — 仅提取道具特征
- 组合使用："参考服装和发型，面部自己描述"

### 动漫→真人映射规则

当参考图为动漫/二次元风格时：
- 面部特征转为"类动漫风格的五官比例，但呈现真人肌肤质感和光影"
- 发色保留原色，发型转为可实现的真人发型描述
- 服装保留原设计，材质转为真实面料描述

### 真人→cosplay映射规则

当参考图为真人照片时：
- 面部特征保留，作为"参考人物"使用
- 发型尽可能保留，必要时调整以适配cosplay角色
- 服装替换为子模板的cosplay造型
