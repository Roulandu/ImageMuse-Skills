# 屏幕成真（screen）

人物从电子屏幕类媒介中破壁而出的超现实人像路线，包括手机屏幕、电脑屏幕、平板屏幕三类显示设备。

## 子路线表格

| 子路线 ID | 中文名 | 核心触发关键词 |
| --- | --- | --- |
| `phone-screen` | 手机屏幕 | 手机里、手机屏幕、从手机里出来、phone screen、手机屏 |
| `computer-screen` | 电脑屏幕 | 电脑屏幕、显示器、从电脑里出来、computer screen、显示屏 |
| `tablet-screen` | 平板屏幕 | 平板屏幕、iPad、从平板里出来、平板里 |

## 匹配规则

优先匹配更具体的关键词。当多个子路线关键词同时命中时，取最具体的设备类型匹配结果。所有设备品牌、系统界面使用虚构替代。
