# 印刷品成真（print）

人物从印刷品类媒介中破壁而出的超现实人像路线，包括杂志封面、电影海报、户外广告牌、明信片、邮票、书籍封面、老照片冲印七类印刷媒介。

## 子路线表格

| 子路线 ID | 中文名 | 核心触发关键词 |
| --- | --- | --- |
| `magazine-cover` | 杂志封面 | 杂志封面、magazine cover、杂志里 |
| `movie-poster` | 电影海报 | 电影海报、poster、从海报里出来 |
| `billboard` | 户外广告牌 | 广告牌、billboard、户外广告、高炮 |
| `postcard` | 明信片 | 明信片、postcard |
| `postage-stamp` | 邮票 | 邮票、stamp |
| `book-cover` | 书籍封面 | 书籍封面、book cover、书封、从书里出来 |
| `old-photo` | 老照片冲印 | 老照片、old photo、冲印、照片里出来、老相片 |

## 匹配规则

优先匹配更具体的关键词。当多个子路线关键词同时命中时，取最具体的印刷品类型匹配结果。所有刊物名称、电影名称、品牌名称使用虚构替代。
