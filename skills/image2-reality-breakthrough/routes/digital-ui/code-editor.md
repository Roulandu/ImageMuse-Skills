# 代码编辑器

## 触发关键词
代码编辑器、code editor、ide、编辑器、从代码里出来、程序员、代码生成

## 视觉指纹
一个代码编辑器窗口里写着代码，代码生成的人物从编辑器窗口里浮现出来，上半身完全写实，代码行、语法高亮、光标闪烁在过渡区域流动，人物像是被代码"编译"出来的AI形象。

## 过渡模板
- 完全写实区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理，人物从代码中"生成"出来
- 过渡融合区域：腰腹部到编辑器平面，有代码行流动、粒子像素、语法高亮色彩、光标闪烁的渐变效果
- 纯媒介区域：代码编辑器界面，是2D平面IDE，有代码行（虚构代码）、语法高亮、行号、侧边栏、标签页、终端窗口
- 过渡方式：从代码编辑器中"编译出来"，人物由代码行汇聚成形，越往上越真实，越往下越像素/代码化

## 默认主体气质
原创成年东方女性，20岁及以上，气质科技极客，五官清秀聪明，表情专注灵动，像一个由AI生成的虚拟程序员。

## 默认画幅
16:9 横版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
电脑屏幕代码编辑器界面（虚构IDE，如「CodeVerse」风格）
编辑器元素：代码行、语法高亮颜色、行号、侧边文件树、标签页、终端、光标闪烁
环境道具：机械键盘、多屏显示器、咖啡杯、桌面小摆件
光线：屏幕冷蓝光 + 暖色台灯，程序员深夜氛围
人物一只手放在键盘上，从代码中浮现出来
