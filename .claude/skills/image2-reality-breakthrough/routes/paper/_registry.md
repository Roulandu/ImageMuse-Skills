# 纸上成真（paper）

人物从纸张类媒介中破壁而出的超现实人像路线，包括时尚设计稿、漫画动漫、服饰设定稿、国画水墨画四类纸本媒介。

## 子路线表格

| 子路线 ID | 中文名 | 核心触发关键词 |
| --- | --- | --- |
| `fashion-sketch` | 时尚设计稿 | 时尚设计稿、时装插画、fashion sketch、设计师手稿、服装设计图 |
| `comic-manga` | 漫画/动漫 | 漫画、动漫、manga、comic、从漫画里出来、漫画面板 |
| `design-sheet` | 服饰设定稿 | 服饰设定稿、服装设计稿、设定稿、角色设定 |
| `chinese-painting` | 国画/水墨画 | 国画、水墨画、水墨、从画里走出来、古画、宣纸 |

## 匹配规则

优先匹配更具体的关键词。当多个子路线关键词同时命中时，取最具体的纸本类型匹配结果。所有出版物名称、作品名称使用虚构替代。
