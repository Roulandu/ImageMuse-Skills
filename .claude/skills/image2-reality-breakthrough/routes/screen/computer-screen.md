# 电脑屏幕

## 触发关键词
电脑屏幕、显示器、从电脑里出来、computer screen、显示屏、从显示器里出来、桌面壁纸

## 视觉指纹
一张现代办公桌上放着一台宽屏显示器，屏幕亮着显示一张人物壁纸，壁纸中的人物身体直接穿过屏幕玻璃，以真实 3D 立体质感探出屏幕平面，另一部分仍留在屏幕内以 2D 桌面壁纸形式存在，屏幕边缘有蓝紫色的光晕和像素流动效果。

## 过渡模板库

### 模板A：俯身探出头 + 斜向切面（默认推荐）
- 完全 3D 区域：头部、一侧肩颈、上半身胸腔及同侧手臂，人物俯身从屏幕中探出，手臂向前伸出仿佛要触碰现实中的键盘，真实皮肤纹理和衣物质感，有明确的体积感和光影层次
- 过渡融合区域：从一侧肩部斜向延伸至对侧腰髋部的斜线切面与屏幕玻璃平面重合处，有像素化、扫描线和屏幕辉光效果，RGB 色彩分离，仿佛人物正在突破像素矩阵
- 完全 2D 区域：屏幕内的另一侧身体及腰以下腿部，是电脑壁纸中的 2D 平面图像，有像素网格、屏幕反光、色温偏冷，呈现明确的平面图像质感，无体积感
- 过渡方式：人物俯身从电脑屏幕玻璃平面中斜向探出上半身，屏幕外为 3D 真人，屏幕内为同一人的 2D 数字影像，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板B：玻璃碎裂飞溅 + 仰身冲出
- 完全 3D 区域：头部、肩颈、上半身及双臂，完全立体写实，真实皮肤纹理和衣物质感，头发和衣物向后飞扬有动感，双臂微张仿佛刚冲破屏障，有明确的体积感和光影层次
- 过渡融合区域：胸肩区域周围的屏幕玻璃呈放射状碎裂，多块大小不一的玻璃碎片飞溅悬浮在空中，碎片边缘有冷蓝色的屏幕光折射，桌面图标和任务栏元素从碎裂处飞出
- 完全 2D 区域：屏幕内的腰以下及腿部，是电脑壁纸中的 2D 平面图像，透过未碎裂的屏幕区域可见，有像素网格、屏幕反光、色温偏冷，呈现明确的平面图像质感，无体积感
- 过渡方式：人物冲破电脑屏幕玻璃，玻璃呈放射状碎裂飞溅，人物从碎裂缺口中冲出，屏幕外为 3D 真人，屏幕内为同一人的 2D 数字影像

### 模板C：跪爬浮现式 + 像素溶解
- 完全 3D 区域：头部、肩颈、上半身及双手，人物双手撑在屏幕边缘（不碰边框），身体从屏幕平面中缓缓浮现爬出，低视角有突破束缚的张力，真实皮肤纹理和衣物质感，有明确的体积感和光影层次
- 过渡融合区域：躯干中部与屏幕玻璃平面重合处，有像素溶解和粒子飘散效果，像素颗粒沿着身体轮廓向上飘散，屏幕中的桌面图标在溶解区域扭曲变形
- 完全 2D 区域：屏幕内的腰以下及腿部，是电脑壁纸中的 2D 平面图像，有像素网格、屏幕反光、色温偏冷，呈现明确的平面图像质感，无体积感
- 过渡方式：人物双手撑在屏幕平面上从电脑屏幕中爬出，上半身已凝聚为 3D 真人，下半身仍在像素溶解状态，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板D：迈步走出全身 + 办公桌场景
- 完全 3D 区域：头部、躯干、双臂及一条腿的大部分，已完全走出屏幕，前脚已经踩在真实的办公桌上，重心在前脚，身体微微前倾呈迈步动态，真实皮肤纹理、服装面料褶皱清晰分明
- 过渡融合区域：另一条腿的小腿处与屏幕平面重合，有像素溶解和粒子飘散效果，身后飘散着桌面图标、文件夹、光标箭头等数字元素，发梢和裙摆还带着淡淡的像素残留
- 完全 2D 区域：屏幕内的后脚及鞋履，是电脑壁纸中的 2D 平面图像，有像素网格、屏幕反光、色温偏冷，呈现明确的平面图像质感，无体积感
- 过渡方式：人物从电脑屏幕中迈步走出，一只脚已踩在现实的办公桌上，身后飘散着数字界面元素，身上带着像素残留，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，五官精致立体，气质干练都市，眼神自信带点调皮，像一个从数字世界逃出来的精灵。

## 默认画幅
16:9 横版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
现代简约办公桌、宽屏显示器（无品牌标识）、机械键盘一角、鼠标、桌面小绿植、咖啡杯
屏幕界面：虚构的桌面壁纸界面、任务栏图标、桌面图标（通用样式，不用真实OS）
人物身体穿过屏幕平面，俯身或跪爬姿势，手臂前伸
光线：屏幕冷光 + 室内暖光，形成冷暖对比
光影：破壁人物在桌面和键盘上投下真实的阴影，阴影带冷色调屏幕光影响，增强破壁真实感
