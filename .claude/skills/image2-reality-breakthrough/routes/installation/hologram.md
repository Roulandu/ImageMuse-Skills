# 全息投影

## 触发关键词
全息投影、hologram、全息、3D投影、从全息里出来、投影人物、全息影像

## 视觉指纹
一个科技感空间中，全息投影的人物身体直接穿过投影源平面，上半身以真实 3D 立体质感从投影光束中凝聚成形，下半身仍留在投影光场内以光点组成的 2D 全息影像形式存在，投影仪发出的光束、粒子和扫描线在人物周围流动。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，人物从全息投影中"实体化"，明显从光场中脱离出来
- 过渡融合区域：腰胯部与投影源平面重合处，有光点粒子凝聚、光束扫描、半透明渐变、色彩分层的效果；贴附在投影光场内的扫描线、粒子光点等元素被人物身体正确遮挡；少量光粒子从过渡区域飘散，主要在人物身后和侧面
- 完全 2D 区域：全息投影下半部分及设备，是由光点组成的全息影像效果，有粒子、扫描线、半透明、投影仪光束、色散，呈现明确的光粒子平面质感，无体积感
- 过渡方式：人物身体直接穿过全息投影光场平面，光场之前为 3D 真人实体，光场之内为同一人的 2D 光点影像，以投影平面为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质未来科幻，五官精致完美，表情冷静智慧，像一个来自未来的AI全息助手。

## 默认画幅
3:4 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
未来科技感空间、全息投影设备（虚构品牌）
全息元素：粒子光点、扫描线、光束、半透明分层、色散、投影仪、操作界面
环境道具：金属墙面、控制台、悬浮屏幕、未来感家具
光线：冷蓝光 + 粒子发光，科技未来感
人物从投影中浮现出来
