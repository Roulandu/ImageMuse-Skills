# 书籍封面

## 触发关键词
书籍封面、book cover、书封、从书里出来、从书封里出来、小说封面

## 视觉指纹
一本精装书立放在木质书架前或平放在桌面上，封面上的人物身体直接穿过书籍封面平面，上半身以真实 3D 立体质感探出身来，下半身仍留在书封内以 2D 平面形式存在，书脊、书名、作者名等封面元素围绕着她，书页的厚度和纹理增加真实感。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，人物从书封中探出身来，明显在封面平面之前
- 过渡融合区域：腰腹部与封面表面平面重合处，有封面印刷质感渐变、装帧纹理融入的效果；贴附在封面上的书名、作者名、推荐语等印刷元素被人物身体正确遮挡
- 完全 2D 区域：书籍封面内的下半身及背景，是平面装帧设计，包括书名（虚构）、作者名（虚构）、推荐语、出版社（虚构），呈现明确的平面印刷质感，无体积感
- 过渡方式：人物身体直接穿过书籍封面平面，封面之前为 3D 真人，封面之内为同一人的 2D 封面上的人物影像，以封面纸面为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质文学知性，五官清秀耐看，眼神沉静有故事，像一本小说的女主角。

## 默认画幅
2:3 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
木质书架 / 书桌、精装书籍（虚构书名）
书籍元素：封面设计、书名位（抽象色块）、虚构作者名位、出版社名位、推荐语位、书脊、书角磨损
环境道具：其他几本书、阅读灯、眼镜、书签、一杯咖啡
光线：温暖的台灯光线，书脊有质感高光
人物上半身从书封中微微探出
