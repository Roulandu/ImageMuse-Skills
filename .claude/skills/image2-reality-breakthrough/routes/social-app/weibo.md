# 微博客 App（虚构：微言）

## 触发关键词
微博、weibo、从微博里出来、热搜、博主照片、微博配图

## 视觉指纹
一部手机屏幕显示着微博客信息流类 App 界面，一条热门动态配图中的人物身体直接穿过屏幕玻璃，以真实 3D 立体质感探出屏幕平面，另一部分仍留在屏幕内以 2D 平面图片形式存在，界面有转发评论点赞图标、话题标签、头像位等信息流元素，人物像是从热搜里"走"出来了。

## 过渡模板库

### 模板A：俯身探出头 + 斜向切面（默认推荐）
- 完全 3D 区域：头部、一侧肩颈、上半身胸腔及同侧手臂，人物俯身从屏幕中探出，仿佛在跟粉丝打招呼，真实皮肤纹理，大方自信的表情，有明确的体积感和光影层次
- 过渡融合区域：从一侧肩部斜向延伸至对侧腰部的斜线切面与屏幕平面重合处，有动态卡片边框发光、话题标签图标飘散和 @ 符号装饰飞出的效果
- 完全 2D 区域：屏幕内的另一侧身体及腰以下部分，是微博客配图中的 2D 平面影像，有手机屏幕像素感、屏幕反光，呈现明确的平面图片质感，无体积感
- 过渡方式：人物俯身从微博客屏幕中斜向探出上半身，屏幕外为 3D 真人，屏幕内为同一人的 2D 信息流配图，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板B：玻璃碎裂飞溅 + 仰身冲出
- 完全 3D 区域：头部、肩颈、上半身及双臂，完全立体写实，真实皮肤纹理，头发和衣物向后飞扬有动感，双臂微张，有明确的体积感和光影层次
- 过渡融合区域：胸肩区域周围的屏幕玻璃呈放射状碎裂，多块大小不一的玻璃碎片飞溅悬浮在空中，碎片之间夹着飞出的话题标签、@符号、转发评论图标等微博元素
- 完全 2D 区域：屏幕内的腰以下部分，是微博客配图中的 2D 平面影像，透过未碎裂的屏幕区域可见，有手机屏幕像素感和屏幕反光，呈现明确的平面图片质感，无体积感
- 过渡方式：人物冲破微博客屏幕玻璃，玻璃呈放射状碎裂飞溅，人物从碎裂缺口中冲出，屏幕外为 3D 真人，屏幕内为同一人的 2D 信息流配图

### 模板C：迈步走出全身 + 话题标签飘散
- 完全 3D 区域：头部、躯干、双臂及一条腿的大部分，已完全走出屏幕，前脚已经踏入现实，重心在前脚，身体微前倾呈行走动态，真实皮肤纹理、服装面料褶皱清晰分明
- 过渡融合区域：另一条腿的小腿处与屏幕平面重合，有像素溶解效果，身后飘散着话题标签、@符号、转发点赞评论图标等信息流元素，发梢和裙摆还带着淡淡的屏幕像素残留
- 完全 2D 区域：屏幕内的后脚及鞋履，是微博客配图中的 2D 平面影像，有手机屏幕像素感和屏幕反光，呈现明确的平面图片质感，无体积感
- 过渡方式：人物从微博客 App 中迈步走出，一只脚已踏入现实，身后飘散着微博信息流元素，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板D：伸手向前 + 像素溶解
- 完全 3D 区域：一只手和前臂完全伸出屏幕，手指仿佛在点触屏幕外的世界，手部有真实皮肤纹理和体积感，是画面的视觉焦点
- 过渡融合区域：手腕和前臂中部与屏幕玻璃平面重合处，有动态卡片边框发光、话题标签图标飘散和像素溶解效果
- 完全 2D 区域：屏幕内的身体其余部分（头部、躯干、另一条手臂、双腿），是微博客配图中的 2D 平面影像，有手机屏幕像素感、屏幕反光，呈现明确的平面图片质感，无体积感
- 过渡方式：人物的一只手臂穿过微博客屏幕伸向观众，手和前臂为 3D 真人质感，身体其余部分仍在屏幕内为 2D 信息流配图，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质大方自信，五官明艳，表情带点从容的微笑，像一个拥有百万粉丝的人气博主。

## 默认画幅
9:16 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
智能手机（无品牌标识）立放、微博客类App界面（虚构品牌，与真实品牌无直接关联）
界面元素：用户头像位、昵称条、认证标识位、装饰性正文条（抽象色块替代具体文字）、配图区域、转发/评论/点赞图标及数字占位、话题标签图标、热搜入口位
人物身体穿过屏幕平面，俯身或伸手姿势，自然大方的姿态
