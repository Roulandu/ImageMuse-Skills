# 短视频 App（虚构：闪拍）

## 触发关键词
抖音、douyin、tiktok、从抖音里出来、短视频、视频号、短视屏

## 视觉指纹
一部手机竖屏显示着短视频社区类 App 界面，一个竖屏视频中的人物身体直接穿过屏幕玻璃，以真实 3D 立体质感探出屏幕平面，另一部分仍留在屏幕内以 2D 视频画面形式存在，界面有右侧互动图标列、底部导航栏、视频进度条等短视频元素，人物仿佛正从播放的视频中走出来跟你打招呼。

## 过渡模板库

### 模板A：仰身冲出 + 玻璃碎裂（默认推荐，动感强）
- 完全 3D 区域：头部、肩颈、上半身及双臂，完全立体写实，真实皮肤纹理，自然生动的表情，头发和衣物向后飞扬有动感，双臂微张仿佛刚冲破屏幕，有明确的体积感和光影层次
- 过渡融合区域：胸肩区域周围的屏幕玻璃呈放射状碎裂，多块大小不一的玻璃碎片飞溅悬浮在空中，碎片之间夹着飞出的心形点赞图标、评论气泡、音乐音符等短视频元素
- 完全 2D 区域：屏幕内的腰以下及腿部，是短视频画面中的 2D 平面影像，透过未碎裂的屏幕区域可见，有视频画面的微模糊感、屏幕像素网格、轻微色偏和扫描线效果，呈现明确的视频画面质感，无体积感
- 过渡方式：人物冲破短视频 App 屏幕玻璃，玻璃呈放射状碎裂飞溅，人物从碎裂缺口中冲出，屏幕外为 3D 真人，屏幕内为同一人的 2D 短视频画面

### 模板B：伸手向前 + 像素扫描线
- 完全 3D 区域：一只手和前臂完全伸出屏幕，手指仿佛在点触观众的方向，手部有真实皮肤纹理和体积感，是画面的视觉焦点
- 过渡融合区域：手腕和前臂中部与屏幕玻璃平面重合处，有视频播放进度光带效果、心形点赞图标飘散、视频扫描线和轻微的像素溶解效果
- 完全 2D 区域：屏幕内的身体其余部分（头部、躯干、另一条手臂、双腿），是短视频画面中的 2D 平面影像，有视频画面的微模糊感、屏幕像素网格、轻微色偏和扫描线效果，呈现明确的视频画面质感，无体积感
- 过渡方式：人物的一只手臂穿过短视频 App 屏幕伸向观众，手和前臂为 3D 真人质感，身体其余部分仍在屏幕内为 2D 视频画面，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板C：迈步走出全身 + 视频帧溶解
- 完全 3D 区域：头部、躯干、双臂及一条腿的大部分，已完全走出屏幕，前脚已经踏入现实空间，重心在前脚，身体微前倾呈行走动态，真实皮肤纹理、服装面料褶皱清晰分明，有明确的体积感和光影层次
- 过渡融合区域：另一条腿的小腿处与屏幕平面重合，有视频帧叠影溶解效果、进度条光带、点赞和评论图标从身后飘散飞出，发梢和裙摆还拖着视频帧的残影
- 完全 2D 区域：屏幕内的后脚及鞋履，是短视频画面中的 2D 平面影像，有视频画面的微模糊感、屏幕像素网格和扫描线效果，呈现明确的视频画面质感，无体积感
- 过渡方式：人物从短视频 App 中迈步走出，一只脚已踏入现实，身后拖着视频帧残影和飘散的互动图标，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板D：俯身探出头 + 斜向切面
- 完全 3D 区域：头部、一侧肩颈、上半身胸腔及同侧手臂，人物俯身从屏幕中探出，仿佛在跟观众打招呼，真实皮肤纹理，生动的表情，有明确的体积感和光影层次
- 过渡融合区域：从一侧肩部斜向延伸至对侧腰部的斜线切面与屏幕平面重合处，有视频播放进度光带、心形点赞图标飘散、界面透明度渐变和轻微的视频扫描线
- 完全 2D 区域：屏幕内的另一侧身体及腰以下腿部，是短视频画面中的 2D 平面影像，有视频画面的微模糊感、屏幕像素网格、轻微色偏和扫描线效果，呈现明确的视频画面质感，无体积感
- 过渡方式：人物俯身从短视频屏幕中斜向探出上半身，屏幕外为 3D 真人，屏幕内为同一人的 2D 短视频画面，以屏幕玻璃为分界面形成 2D→3D 破壁错觉
