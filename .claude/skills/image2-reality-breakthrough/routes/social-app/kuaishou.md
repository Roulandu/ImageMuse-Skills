# 短视频 App（虚构：快映）

## 触发关键词
快手、kuaishou、从快手里出来、老铁、短视频平台

## 视觉指纹
一部手机竖屏显示着短视频社区类 App 界面，一个生活类短视频中的人物身体直接穿过屏幕玻璃，上半身以真实 3D 立体质感探出屏幕平面，下半身仍留在屏幕内以 2D 视频画面形式存在，界面有互动图标列、关注按钮、底部导航等短视频元素，人物像是从日常视频里"走"出来跟你打招呼。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身胸腔，完全立体写实，真实皮肤纹理，自然生活化的妆容和表情，有明确的体积感和光影层次，明显高出屏幕玻璃平面
- 过渡融合区域：腰腹部与屏幕玻璃平面重合处，有视频播放进度条的光带效果、点赞红心飘散和界面透明度渐变
- 完全 2D 区域：屏幕内的腰以下部分，是短视频画面中的 2D 平面影像，有视频画面质感、屏幕像素网格、轻微色温偏移，呈现明确的视频画面平面感，无体积感
- 过渡方式：人物身体直接穿过手机屏幕玻璃平面，屏幕外为 3D 真人，屏幕内为同一人的 2D 短视频画面，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质亲切自然，五官端正耐看，笑容真诚温暖，像一个你关注了很久的生活分享博主。

9:16 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图
