# Image2 Reality Breakthrough

## 技能定位

本技能用于生成「人物从 2D 媒介破壁进入现实世界」的超现实人像摄影提示词。核心是制造 2D 平面内容与 3D 真实人物在同一画面中的过渡错觉，人物身体的一部分留在媒介内，另一部分突破媒介表面进入现实空间，形成强烈的视觉冲击感。

**做什么：**
- 八大媒介路线：纸上成真、屏幕成真、社交 App、印刷品、艺术画作、复古媒介、数字界面、装置场景
- 提供子路线级别的视觉指纹、过渡模板、场景道具、负面词补充
- 输出合同级中文提示词，含破壁设定卡与过渡效果描述

**不做什么：**
- 不生成纯 2D 插画、纯屏幕截图、纯平面设计稿
- 不生成未成年、不生成露骨内容、不用真人/真品牌/真角色名
- 不生成暴力、血腥、恐怖主题的破壁内容

## 工作流

1. 加载核心契约文件（按 Required load order 所列顺序）
2. 解析用户输入，锁定安全参数（根据 `parameter-schema.md`）
3. **快速模式检测**：用户输入同时满足以下条件 → 跳过步骤 4-8，直接进入步骤 9（组装输出）：
   - 包含"破壁"关键词
   - 包含明确的路线/媒介关键词（可唯一匹配大路线+子路线）
   - 无额外定制需求关键词（如"有创意""柔美""科技感""震撼""换个姿势""斜侧"等）
   - 快速模式默认值：子路线默认过渡模板 + 半身用 lean-forward / 全身用 step-out + 单反质感 + 子路线默认画幅
4. 识别大路线（8 选 1）：匹配成功则进入步骤 5；匹配失败则返回 8 个大路线选项供用户选择
5. 加载大路线 `./routes/{routeId}/_registry.md`
6. 识别子路线：用户输入关键词在当前大路线下唯一命中一个子路线 → 直接锁定；匹配多个或无法确定 → 返回该大路线下所有子路线选项
7. 加载子路线文件 `./routes/{routeId}/{subRouteId}.md`，获取视觉指纹、过渡模板库、默认主体、默认画幅、场景道具、负面词补充
8. 锁定图片风格：用户指定 → 使用用户指定；未指定 → 默认单反写真质感
9. 组装输出契约（按 `output-contract.md` 规定的格式）
10. 应用质量门（通用质量门 + 破壁专项质量门）
11. 返回结果

## 分步交互规则

快速模式优先：用户输入满足快速模式条件时，一步直接输出结果，无任何交互步骤。

以下两种未完成状态，仅返回对应选择项，不生成最终提示词：

- **路线未选**（大路线缺失且快速模式不适用）：返回 8 大路线的中文名 + 一句话简介，供用户选择
- **子路线未选**（大路线已选、子路线缺失且用户输入无法唯一匹配）：返回该大路线下所有子路线的中文名 + 核心触发关键词，供用户选择。若用户输入关键词可唯一命中（如"手机"唯一命中 phone-screen），则直接锁定，不返回选择列表

图片风格不再阻塞流程：未指定时默认使用单反写真质感。

## 子路线文件格式说明

每个子路线文件包含以下 7 个字段：

1. **触发关键词**：用于匹配用户输入的关键词列表
2. **视觉指纹**：该子路线独有的视觉特征、材质、色彩、质感描述
3. **过渡模板库**：多种破壁过渡写法模板（含默认推荐项），描述人物如何从媒介中突破出来
4. **默认主体气质**：适配该子路线的默认人物气质描述
5. **默认画幅**：推荐的画幅比例与方向
6. **场景与道具**：配合破壁效果的背景环境与道具元素
7. **负面词补充**：该子路线特有的负面限制词补充

### 过渡模板统一编写规范

所有过渡模板必须严格遵循破壁第一法则，统一使用以下四段式结构：

- **完全 3D 区域**：明确列出人物哪些身体部位在媒介之外，必须是真实立体的真人质感。强调"真实皮肤纹理、体积感、3D 立体"。
- **过渡融合区域**：明确描述身体穿过媒介平面的位置（如"胸腰交界处"、"髋部平面"），以及过渡效果的具体形态（发光、像素溶解、笔触渐变、纸张撕裂等）。
- **完全 2D 区域**：明确列出人物哪些身体部位在媒介内部，必须呈现该媒介特有的平面质感（屏幕像素、印刷网点、画笔笔触、UI 平面等）。强调"平面感、无体积、2D 影像"。
- **过渡方式总结**：一句话概括破壁的核心视觉——必须包含"身体穿过媒介平面"的表述，禁止出现"手扶边框"、"站在旁边"等会导致画框效应的描述。

## 六大过渡效果类型（全局共享）

子路线的过渡模板库必须从以下 6 种类型中选择适配项，每种类型对应不同的视觉语言和叙事感：

| 类型 ID | 中文名 | 过渡形态 | 适用场景 | 视觉关键词 |
| --- | --- | --- | --- | --- |
| `horizontal-cut` | 水平切面式 | 身体水平穿过媒介平面，分界线近似水平直线 | 基础款、电商、标准人像 | 干净利落、界面元素沿切面飘散 |
| `diagonal-cut` | 斜向切面式 | 身体以斜线角度穿过媒介，分界线从肩部斜向延伸至对侧腰部 | 动感款、时尚、运动感 | 斜向张力、不对称构图、动态感 |
| `tear-rip` | 撕裂破洞式 | 媒介表面被人物撕开一个不规则破洞，人物从破洞中挤出，破洞边缘有撕裂褶皱/碎裂玻璃/翘曲纸张 | 力量感、冲击感、戏剧性 | 不规则边缘、撕扯痕迹、碎片飞溅 |
| `dissolve-pixel` | 溶解像素式 | 身体在媒介平面处逐渐溶解为像素粒子/油墨颗粒/笔触碎片，上半身凝聚为真人，下半身消散为媒介材质 | 梦幻感、科技感、艺术感 | 粒子飘散、渐变过渡、由虚到实 |
| `shatter-shard` | 碎裂飞溅式 | 媒介表面碎裂成多块碎片飞散，人物从碎裂缺口中冲出，碎片悬浮在空中 | 爆发力、震撼感、动作感 | 玻璃碎片/纸片飞散、缺口不规则、冲击力 |
| `wave-ripple` | 波动涟漪式 | 媒介表面像水面一样产生波纹涟漪，人物从波纹中央浮现穿出，媒介边缘有液体般的扭曲变形 | 柔美感、超现实、水元素 | 波纹扭曲、液面折射、柔化边缘 |

**选用规则：** 每个子路线至少提供 3 种过渡类型，默认推荐一种。用户无特殊要求时使用默认项；用户说"更有创意"、"更动感"、"更震撼"时，优先推荐 `tear-rip`、`shatter-shard` 或 `diagonal-cut`；用户说"更柔美"、"更梦幻"时，优先推荐 `dissolve-pixel` 或 `wave-ripple`。

## 破壁姿势库（全局共享）

打破"直立上半身探出"的单一姿势，提供 6 种创意破壁姿势，每种姿势配套对应的过渡位置和叙事逻辑：

| 姿势 ID | 中文名 | 身体语言 | 过渡位置 | 适用场景 |
| --- | --- | --- | --- | --- |
| `step-out` | 迈步走出式 | 一条腿已踏出媒介，重心在前脚，身体微前倾，有行走中的动态感 | 大腿中部 / 膝盖高度 | 全身破壁、电商、日常感 |
| `lean-forward` | 俯身探出头 | 上半身从媒介中俯身探出，手肘或手撑在媒介边缘（不是扶边框），头部靠近观众，有好奇心和互动感 | 胸腰交界处 | 半身破壁、社交App、亲切感 |
| `side-slip` | 侧身滑出式 | 身体以侧面角度从媒介中滑出，一肩在前一肩在后，身体呈对角线构图，优雅有神秘感 | 肩髋斜线 | 时尚感、艺术感、杂志路线 |
| `crawl-emerge` | 跪爬浮现式 | 双手和膝盖支撑，身体从媒介平面中缓缓浮现/爬出，低视角，有突破束缚的张力 | 躯干中部 | 戏剧性、力量感、艺术创作 |
| `burst-through` | 仰身冲出式 | 身体后仰冲出，头部微抬，双臂展开或上扬，头发和衣物向后飞扬，有爆发和自由感 | 腰部 / 髋部 | 运动、能量感、庆祝氛围 |
| `reach-out` | 伸手向前式 | 一只手臂和手已完全伸出媒介并伸向观众，身体大部分仍在媒介内，手是视觉焦点，有强烈的互动和邀请感 | 手腕 / 前臂 | 半身特写、互动感、社交App |

**选用规则：** 用户说"全身"时优先 `step-out` 或 `burst-through`；说"半身"或默认时优先 `lean-forward` 或 `reach-out`；说"时尚"、"高级"时优先 `side-slip`；说"动感"、"有力量"时优先 `crawl-emerge` 或 `burst-through`。

## 破壁角度与构图

除了正面穿出，增加 4 种破壁角度，避免所有图都是"人正对着屏幕穿出来"：

1. **正面穿出（默认）**：人物面向观众，身体从媒介平面垂直穿出，最经典的破壁视角
2. **斜侧 45 度**：媒介和人物均呈 45 度角，人物从斜前方穿出，能看到媒介的侧面厚度和人物的立体感
3. **侧方滑出**：媒介呈侧立面，人物从侧面方向穿出/滑出，强调身体的侧面轮廓和流线感
4. **俯角冲出**：观众视角略高，人物从下方媒介中向上冲出，有突破天花板的视觉张力
5. **仰角浮现**：观众视角略低，人物从上方媒介中向下探出头，有压迫感和神秘感

## 破壁方向（正向/反向）

除了默认的「人物从媒介中冲出」的正向破壁，支持反向破壁——人物从现实世界被吸入媒介。

| 方向 | ID | 视觉描述 | 叙事感 | 触发词 |
|------|-----|---------|--------|--------|
| 正向破壁（默认） | `outward` | 人物从媒介中冲出/走出，2D→3D | 自由、突破、力量 | 无（默认） |
| 反向破壁 | `inward` | 现实人物正在被吸入媒介，3D→2D | 迷失、穿越、悬念 | 反向破壁、被吸进去、被拉进去、从现实进入、反向 |

### 反向破壁视觉指南

反向破壁的核心是"媒介在吞噬人"——上半身仍是 3D 真人，但下半身正在像素化/油墨化/平面化，被一股力量拖入媒介。

**反向破壁的四段式模板结构（与正向对称）：**
- 完全 3D 区域：人物身体仍处于现实空间的部分，完全立体写实，真实皮肤纹理，有逃离的动态感（挣扎、后仰、伸手抓住现实物体）
- 过渡融合区域：身体被媒介吸入的分界处，指尖/发梢/衣角已经开始变成 2D 平面影像，媒介边缘有向内吸拢的视觉引力感（漩涡、光线汇聚、碎片倒流进入媒介）
- 完全 2D 区域：已被吸入媒介的身体部分，完全呈现该媒介的平面质感，已无 3D 体积感
- 过渡方式：现实人物正在被吸入媒介平面，身体 3D→2D 反向过渡，媒介边缘有吞噬性的视觉引力

**反向破壁关键视觉特征：**
- 人物表情：挣扎/惊讶/迷离/不舍，不是正向破壁的自由和喜悦
- 头发和衣物飘动方向：向媒介方向飘动（被吸进去），而非向外飞扬
- 媒介边缘：漩涡、光线汇聚、碎片倒流，强调"吸入"的视觉引力
- 手部：可能抓住现实中的物体（桌子边缘、画框），试图抵抗吸入
- 媒介残留：进入媒介的身体部分边缘有正在平面化的过渡痕迹

**选用规则：** 用户说"反向破壁""被吸进去""被拉进去""从现实进入XX""反向"时，切换到 `inward` 方向。子路线文件中标注了反向模板的优先使用。

## 全身破壁的创意叙事指南

"全身走出"不等于"把分界线移到脚踝 + 人站着"。全身破壁必须具备**叙事性和瞬间感**——让人能想象出"前一秒和后一秒"发生了什么。

### 全身破壁三要素

1. **动作瞬间感**：不是静止站立，而是正在进行中的动作（迈步的瞬间、刚踏出的那一步、衣物还在飘动）
2. **媒介残留感**：人物完全走出的部分，身上或周围仍带有媒介的痕迹（裙摆还带着像素颗粒、发梢拖着油墨、鞋跟挂着碎玻璃），证明她"刚从那里来"
3. **现实交互感**：破壁人物与现实环境有物理接触和互动（脚踩在真实桌面上、手碰到了现实中的杯子、影子真实地投落在现实地面上）

### 全身破壁的创意场景模板（按需选用）

- **电商路线**：模特从商品详情页迈步走出，一只脚已经踩在真实的展示台上，另一只脚还带着屏幕像素感，购物袋和价格标签从身后飞散而出
- **社交App路线**：博主从手机里跨步走出，脚下踩着真实的咖啡馆桌面，身后飘散着点赞心形和评论气泡，裙摆还带着滤镜色彩
- **杂志路线**：封面女郎从杂志封面上翻身走下来，一只高跟鞋已经踏在真实的大理石桌面上，纸张边缘在她脚踝处翻卷翘边
- **艺术画作路线**：画中人从油画布上走下来，脚下是真实的木地板，她走过的地方留下了油彩脚印，裙摆还带着笔触纹理

## 物理接触真实感强化

破壁效果成立的关键是"真实感"。必须在提示词中强化以下物理接触细节：

- **阴影**：破壁人物在现实场景中投下真实的阴影，阴影方向与场景光源一致，阴影边缘因距离不同有虚实变化
- **支撑关系**：如果人物脚踩在桌面上，桌面应有轻微的压痕/形变感；如果手撑在媒介边缘，媒介边缘应有受力形变
- **环境交互**：破壁人物带动的气流使现实中的小物体（纸张、窗帘、桌面小物）有轻微飘动
- **光影统一**：破壁后的 3D 人物光影与现实环境光源方向一致，媒介内部的 2D 光影则保留媒介自身的光照逻辑

## 默认值与覆盖规则

- **主体默认**：`原创成年东方女性，20岁及以上，五官精致立体，气质自然真实。`
- **主体覆盖**：用户指定安全主体时，完全替换默认主体描述
- **画幅默认**：`3:4竖版构图，超高清，高分辨率，细节清晰`；子路线有指定画幅时优先使用子路线画幅
- **画幅覆盖**：用户指定画幅时，以用户指定为准
- **子路线默认主体优先于全局默认**：子路线文件中的「默认主体气质」优先于全局默认主体描述，用户指定主体时仍完全覆盖
- **图片风格默认**：默认使用「专业单反相机的写真拍摄质感」。用户未指定时自动使用默认值，输出附带提示「默认使用单反写真质感，可随时改为 iPhone 直出质感」
- **图片风格覆盖**：用户指定其他安全风格时，使用用户风格描述
- **服装默认**：根据子路线默认主体气质搭配得体服装
- **服装覆盖**：用户指定安全服装时，保留用户方向并完善描述
- **姿势默认**：破壁姿势以「身体穿过媒介平面」为核心，默认使用 `lean-forward`（俯身探出头）或 `step-out`（迈步走出，当用户要求全身时）。姿势从「破壁姿势库」中选择，禁止默认设定"手扶媒介边框"的姿势（手出现在边框附近会导致 AI 生成画框效应和多余的手）
- **手部策略**：默认将手藏在画面中或简化处理，一只手臂自然伸出媒介外即可，不刻意描绘手部细节；如用户明确要求手势再添加，但必须同时强化手部解剖正确的负面词
- **过渡类型默认**：默认使用 `horizontal-cut`（水平切面式）。当用户表达"更有创意"、"更震撼"、"更动感"时切换到 `tear-rip`（撕裂破洞式）或 `shatter-shard`（碎裂飞溅式）；当用户表达"更柔美"、"更梦幻"时切换到 `dissolve-pixel`（溶解像素式）或 `wave-ripple`（波动涟漪式）
- **破壁角度默认**：默认使用「正面穿出」。用户要求"更有层次"、"更立体"、"有透视"时，使用「斜侧 45 度」

## 破壁第一法则（不可动摇）

以下三条是破壁效果成立的根本前提，任何一条不满足即为废片，必须在提示词中用最强力度的措辞强调：

1. **单一人物原则**：整幅画面中只有一个人物。媒介内的 2D 影像和破壁而出的 3D 真人是**同一个人的不同部分**，不是两个人、不是双胞胎、不是画中人和画外人的并置。画面中只能出现一张脸、一个主体人物。
2. **2D/3D 分区原则**：以媒介表面（屏幕玻璃、纸面、画布等）为明确分界面——**媒介内部 = 2D 平面影像质感**（照片/插画/印刷品/UI 界面等平面属性），**媒介外部 = 3D 立体真人质感**（真实皮肤纹理、体积感、光影层次）。两者在同一人物身上同时存在，形成"一半在里面一半在外面"的破壁错觉。
3. **身体穿越原则**：人物的身体直接**穿过**媒介平面，一部分留在媒介内（2D），一部分伸出媒介外（3D）。不是"站在媒介旁边"、不是"手扶着媒介边框"、不是"媒介作为画框框住人物"——人物身体本身就是跨越媒介边界的载体。

## 破壁专项质量门

在通用质量门基础上，额外检查以下 15 条：

1. **单一人物**：画面中只有一个人物主体，只有一张脸。媒介内的影像是同一人物的延伸部分，不是独立的第二个人
2. **2D/3D 分区明确**：媒介内部分呈现清晰的 2D 平面质感（像素格/印刷网点/笔触/UI 平面感），媒介外部分呈现真实 3D 立体质感，两者形成可辨识的对比
3. **过渡自然**：2D 与 3D 部分的过渡边界自然可信，撕裂/褶皱/光影/像素溶解过渡合理，无生硬切割感
4. **人物一致**：媒介内的 2D 人物影像与破壁而出的 3D 人物是同一个人，五官、发型、服装、配饰完全一致
5. **身体穿越媒介**：人物身体直接穿过媒介平面，不是手扶边框、不是站在旁边、不是画框效果
6. **物理接触真实**：破壁人物与现实场景有真实的物理接触——接触阴影、压痕、支撑关系明确，无漂浮感
7. **比例协调**：破壁人物与媒介、与现实环境的比例关系协调，透视正确，无尺度违和
8. **媒介内容可信**：媒介内的画面内容符合该媒介的真实特征（分辨率、印刷网点、像素格、笔触等），不出现跨媒介错位
9. **界面文字安全策略**：媒介内的文字内容使用抽象符号、色块、装饰性图形或模糊化处理，不追求可读性，避免出现乱码或疑似真实品牌的文字
10. **无品牌侵权风险**：媒介中不出现真实品牌 Logo、真实杂志名、真实 App 界面、真实角色名；虚构名称与真实品牌在命名、配色、布局上均有显著差异，不存在擦边模仿
11. **过渡有层次**：过渡融合区域不是一条简单的直线切割，而是有厚度和层次的过渡带，包含媒介材质的变形/碎裂/溶解效果
12. **姿势有动态感**：破壁姿势不是僵硬的直立正面站姿，而是有动态、有重心、有叙事感的身体语言
13. **全身破壁有叙事**：全身破壁场景中，人物不是静止站立在媒介前，而是处于"正在走出"的动作瞬间，身上带有媒介残留痕迹，与现实环境有交互
14. **光影统一**：破壁后的 3D 人物光影与现实环境光源方向和强度一致，不出现人物光和环境光打架的情况
15. **无腰斩感**：半身破壁的过渡位置不是水平的腰部硬切，而是配合姿势有斜向/不规则的过渡形态，避免"身体被截断"的不适感

## 输出契约

### 输出语言

所有用户可见内容使用简体中文，除非用户明确要求其他语言。最终 Image2 提示词、负面限制词、可选变化参数均为中文。保留有用的技术术语如 `Image2`、`DSLR`、`RAW`、`8K`、画幅比例等，以保证模型识别清晰度。

### 输出结构

完整模式（`outputMode: complete`）按以下顺序输出：

1. **意图摘要**
2. **已锁定参数**
3. **破壁设定卡**（大路线名、子路线名、过渡类型、媒介特征、破壁方向、物理接触方式）
4. **最终中文提示词**
5. **负面限制词**
6. **可选变化参数**

简洁模式（`outputMode: concise`）：仅返回「最终中文提示词」+「负面限制词」。

破壁设定卡即本技能的导演扩展段，对应共享输出契约中的「导演扩展」位置。

直接出图门：仅当用户说「直接出图」且交互模式为 `direct-image` 时生成图片，其他情况均返回文本。

2. `整张照片必须呈现着专业单反相机的写真拍摄质感，不要出现AI痕迹， 不要过度磨皮，不要过度美颜滤镜`

- **子路线补充负面词**：见各子路线文件

## 可选变化参数

提供 9 个维度的变化建议：

1. **破壁方向**：正向破壁（从媒介中出来）/ 反向破壁（被吸入媒介）
2. **过渡效果类型**：水平切面式 / 斜向切面式 / 撕裂破洞式 / 溶解像素式 / 碎裂飞溅式 / 波动涟漪式
3. **破壁姿势**：俯身探出头 / 迈步走出式 / 侧身滑出式 / 跪爬浮现式 / 仰身冲出式 / 伸手向前式
4. **过渡程度**：轻微探出（头肩）/ 半身破壁（胸腹以上）/ 全身走出（脚踩现实）
5. **破壁角度**：正面穿出 / 斜侧45度 / 侧方滑出 / 俯角冲出 / 仰角浮现
6. **画幅**：竖版 3:4 / 竖版 9:16 / 横版 16:9 / 正方形 1:1
7. **光线**：自然光 / 侧光硬影 / 逆光轮廓 / 冷暖对比
8. **服装**：休闲日常 / 正装 / 运动风 / 国风
9. **媒介风格**：同一路线下可微调媒介的年代感、色彩倾向、磨损程度

## 边界与红线

1. **年龄红线**：不生成未成年人物，不使用幼态、学生、青春校园等暗示未成年的元素
2. **性与暴露红线**：不露骨、不性化、不身体局部凝视、不低机位身体角度
3. **真人与 IP 红线**：不用真人姓名、真实名人相似、真实角色名、真实 IP
4. **品牌侵权红线**：不用真实品牌名、真实杂志名、真实 App 名称与界面，均使用虚构替代
5. **内容主题红线**：不生成暴力、血腥、恐怖、猎奇主题
6. **审美导向**：破壁效果以审美和创意为导向，不制造惊悚或不适感
