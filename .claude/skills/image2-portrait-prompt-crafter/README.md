# image2-portrait-prompt-crafter

人像摄影提示词生成专家 — 根据你的一句话描述，生成专业、完整、可直接用于 Image2 / GPT Image 2 的高质量人像摄影提示词。

## 功能

- 一句话输入 → 专业人像提示词输出
- 覆盖 9 大维度：人物特征、构图、光线、焦段、姿势、场景、服装、风格、后期
- 240+ 条专业摄影知识库
- 四段式输出：画面构想 + 结构化标签 + 完整 Image2 提示词 + 负面提示词

## 何时使用

当用户出现以下任一情况时调用本技能：

- 提供了一句话或简短的人像画面描述，想要 AI 生图提示词
- 询问"帮我写一个人像摄影的 prompt"
- 想优化已有的人像提示词，使其更专业
- 需要人像摄影相关的构图、光线、风格等专业建议

## 输出格式

1. **画面构想** — 整体画面描述（100-200 字）
2. **结构化标签** — 8 维度专业参数（人物、构图、光线、焦段、姿势、场景、风格、后期）
3. **Image2 中文提示词** — 可直接复制使用的完整提示词
4. **避坑提示（负面提示词）** — 避免常见 AI 生图问题

## 创意强度

- **默认「平衡」**：专业但不过分超出用户描述
- 如果用户说"大胆一点"、"有创意"、"超现实"等，自动提升创意强度，给出更大胆的构图/光线/风格组合
