# 场景与环境

> 人像摄影知识库 — 场景与环境模块，从 image2-portrait-prompt-crafter 提取，供各 Skill 共享引用。

---

## 场景空间模板

选择地点后，必须补全六项关系，而不是只列布景：

1. 人物位于场景的具体区域；
2. 支撑面、接触点和人物来向/去向；
3. 一个关键环境锚点及其与人物的距离；
4. 前景—人物—背景顺序与允许遮挡范围；
5. 场景主轴、拍摄轴线和消失点关系；
6. 场景如何作用于人物、衣料、发丝、光线或动作。

环境识别信号默认不超过三个。道具必须被触碰、使用、留下痕迹或承担线索，否则删除。


### 花海/花田 (Flower Field)
**效果：** 密集花朵铺满视野，人物被环抱，浪漫梦幻。
**关键词：** flower field, 花海, 鲜花环绕, 浪漫
**场景：** 少女写真、情侣写真、森系童话、春日。

### 森林/树林 (Forest / Woods)
**效果：** 高大树木垂直空间，枝叶光斑，静谧神秘。
**关键词：** forest, 森林, 林间光影, dappled light, 森系
**场景：** 森系人像、精灵风、情绪写真、婚纱外景。

### 海边/沙滩 (Beach / Seaside)
