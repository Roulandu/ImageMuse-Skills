# 艺术画作成真（art-painting）

人物从艺术画作类媒介中破壁而出的超现实人像路线，包括油画、水彩画、水墨国画、素描、壁画、涂鸦墙六类绘画媒介。

## 子路线表格

| 子路线 ID | 中文名 | 核心触发关键词 |
| --- | --- | --- |
| `oil-painting` | 油画 | 油画、oil painting、从油画里出来 |
| `watercolor` | 水彩画 | 水彩画、watercolor、水彩 |
| `ink-painting` | 水墨国画 | 水墨国画、ink painting、水墨画、国画 |
| `sketch` | 素描 | 素描、sketch、pencil drawing、铅笔画 |
| `mural` | 壁画 | 壁画、mural、wall painting、墙绘 |
| `graffiti` | 涂鸦墙 | 涂鸦、graffiti、街头涂鸦、涂鸦墙 |

## 匹配规则

优先匹配更具体的关键词。当多个子路线关键词同时命中时，取最具体的画种匹配结果。所有艺术家姓名、作品名称使用虚构替代。
