# 手机屏幕

## 触发关键词
手机里、手机屏幕、从手机里出来、phone screen、手机屏、从手机里走出来、手机相册

## 视觉指纹
一部黑色智能手机亮着屏幕，显示一张人物照片，照片中的人物身体直接穿过屏幕玻璃，以真实 3D 立体质感探出屏幕平面进入现实空间，另一部分仍留在屏幕内以 2D 平面照片形式存在，屏幕边缘有过渡效果和像素扩散，形成"从手机里出来"的超现实错觉。

## 过渡模板库

### 模板A：斜向切面式（默认推荐）
- 完全 3D 区域：头部、一侧肩颈、上半身胸腔及同侧手臂，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，肩膀和手臂明显高出屏幕玻璃平面
- 过渡融合区域：从一侧肩部斜向延伸至对侧腰髋部的斜线切面与屏幕玻璃平面重合处，有像素化扩散、屏幕辉光和色彩溢出效果，切面不是直线而是略带不规则的像素锯齿边缘
- 完全 2D 区域：屏幕内的另一侧身体及腰以下腿部，是手机照片中的 2D 平面影像，有手机屏幕的像素网格、反光和色彩偏移，呈现明确的平面照片质感，无体积感
- 过渡方式：人物身体以斜向角度穿过手机屏幕玻璃平面，屏幕外为 3D 真人，屏幕内为同一人的 2D 照片影像，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板B：俯身探出头 + 水平切面
- 完全 3D 区域：头部、肩颈、上半身胸腔，人物俯身从屏幕中探出，手肘微曲撑在屏幕平面附近（不碰边框），真实皮肤纹理和发丝细节清晰，有明确的体积感和光影层次
- 过渡融合区域：胸腰交界处与屏幕玻璃平面重合处，有像素化扩散、屏幕辉光和色彩溢出效果，衣物边缘有轻微的像素拖影
- 完全 2D 区域：屏幕内的腰以下及腿部，是手机照片中的 2D 平面影像，有手机屏幕的像素网格、反光和色彩偏移，呈现明确的平面照片质感，无体积感
- 过渡方式：人物俯身从手机屏幕玻璃平面中探出上半身，屏幕外为 3D 真人，屏幕内为同一人的 2D 照片影像，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板C：玻璃碎裂飞溅式
- 完全 3D 区域：头部、肩颈、上半身及双臂，完全立体写实，真实皮肤纹理，衣物和头发向后飞扬有动感，有明确的体积感和光影层次，明显高出屏幕玻璃平面
- 过渡融合区域：胸肩区域周围的屏幕玻璃呈放射状碎裂，多块大小不一的玻璃碎片飞溅悬浮在空中，碎片边缘有锋利的反光和折射，人物从碎裂缺口中冲出
- 完全 2D 区域：屏幕内的腰以下及腿部，是手机照片中的 2D 平面影像，透过未碎裂的屏幕区域可见，有手机屏幕的像素网格和反光，呈现明确的平面照片质感
- 过渡方式：人物冲破手机屏幕玻璃，玻璃呈放射状碎裂飞溅，人物从碎裂缺口中冲出，屏幕外为 3D 真人，屏幕内为同一人的 2D 照片影像

### 模板D：迈步走出全身 + 像素溶解
- 完全 3D 区域：头部、躯干、双臂及一条腿的大部分，已完全走出屏幕，脚踩在真实桌面上，重心在前脚，身体微前倾呈迈步动态，真实皮肤纹理、服装面料褶皱清晰分明，有明确的体积感和光影层次
- 过渡融合区域：另一条腿的小腿和脚踝处与屏幕玻璃平面重合，有像素溶解和粒子飘散效果，发梢和裙摆还拖着淡淡的像素颗粒痕迹，证明刚从屏幕中走出
- 完全 2D 区域：屏幕内的后脚及鞋履，仍为手机照片中的 2D 平面影像，有手机屏幕的像素网格、反光和色彩偏移，呈现明确的平面照片质感，无体积感
- 过渡方式：人物迈步从手机屏幕中走出，一只脚已踩在现实桌面上，另一只脚还在屏幕内，身上带着像素残留，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板E：伸手向前式
- 完全 3D 区域：一只手和前臂完全伸出屏幕，手指伸向观众方向，手部有真实皮肤纹理、指甲细节和体积感，是画面的视觉焦点
- 过渡融合区域：手腕和前臂中部与屏幕玻璃平面重合处，有像素化扩散和屏幕辉光效果，手臂周围的屏幕像素有轻微的扭曲变形
- 完全 2D 区域：屏幕内的身体其余部分（头部、躯干、另一条手臂、双腿），是手机照片中的 2D 平面影像，有手机屏幕的像素网格、反光和色彩偏移，呈现明确的平面照片质感，无体积感
- 过渡方式：人物的一只手臂穿过手机屏幕玻璃伸向观众，手和前臂为 3D 真人质感，身体其余部分仍在屏幕内为 2D 影像，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，皮肤白皙自然，五官精致，气质甜美灵动，眼神惊喜好奇，仿佛刚从手机世界里发现了出口。

## 默认画幅
9:16 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
黑色智能手机立放在桌面上（无品牌标识）、屏幕亮着、显示相册照片界面、屏幕有轻微反光和指纹
人物身体穿过屏幕平面，采用斜向或俯身姿势穿出，一只手臂自然伸向画面外
背景：温暖的室内环境，柔和的桌面灯光，轻微景深虚化
手机界面元素：状态栏图标、时间数字位、电量图标、相册标题位（抽象文字条）
光影：破壁人物在桌面投下真实的阴影，阴影方向与环境光一致，增强破壁真实感
