# 户外广告牌

## 触发关键词
广告牌、billboard、户外广告、高炮、从广告牌里出来、户外大屏

## 视觉指纹
夜晚城市街道旁，一块大型户外广告牌亮着灯，广告中的人物身体直接穿过广告牌画面平面，上半身以真实 3D 立体质感站在广告牌前的现实空间中，下半身仍留在广告牌画面内以 2D LED 显示形式存在，霓虹灯光和广告牌冷光交织在人物身上，形成强烈的都市超现实感。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，人物站在广告牌前的地面上
- 过渡融合区域：腿部与广告牌画面平面重合处，有 LED 像素点渐变、广告牌灯光晕染、色彩分离效果；贴附在广告牌表面的发光文字、slogan、产品图等元素被人物身体正确遮挡
- 完全 2D 区域：广告牌画面中的下半身和背景，是 LED 大屏显示的平面广告效果，有像素点、发光文字、slogan（虚构品牌），呈现明确的平面广告质感，无体积感
- 过渡方式：人物身体直接穿过广告牌画面平面，广告牌之前为 3D 真人，广告牌之内为同一人的 2D 广告影像，以大屏平面为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质都市摩登，五官明艳大气，表情自信从容，像一个国际品牌的广告代言人。

## 默认画幅
16:9 横版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
夜晚城市街道、大型户外广告牌/高炮（虚构品牌名）
广告牌内容：虚构品牌广告画面、slogan标语位、产品图、品牌logo（全部原创虚构）
城市环境：街道路灯、行驶车辆光轨、玻璃幕墙反射、霓虹招牌
光线：广告牌冷光 + 霓虹暖光 + 路灯混合，高对比度都市夜景
人物一只手轻拂头发，从广告牌中迈出
