# 素描

## 触发关键词
素描、sketch、pencil drawing、铅笔画、从素描里出来、素描人物、速写

## 视觉指纹
一张素描纸夹在画板上放在工作台上，画中的人物身体直接穿过画纸平面，上半身以真实 3D 血肉之躯从铅笔素描中立起来，下半身仍留在纸面内以 2D 铅笔线条形式存在，石墨的颗粒感和阴影排线在过渡区域自然衔接。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，人物从素描纸中"立起来"，明显高出画纸平面
- 过渡融合区域：胸腔到腰腹部与画纸平面重合处，从写实逐渐过渡到铅笔素描，有石墨颗粒融入皮肤、铅笔线条从身体边缘延伸的效果
- 完全 2D 区域：下半身和背景，是纯铅笔素描效果，有明暗排线、结构线、阴影层次、铅笔笔触、纸纹，呈现明确的平面绘画质感，无体积感
- 过渡方式：人物身体直接穿过素描画纸平面，画纸之上为 3D 真人，画纸之内为同一人的 2D 素描画像，以画纸平面为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质安静内敛，五官线条清晰，眼神专注沉静，像一个正在被绘制的艺术模特。

## 默认画幅
4:5 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
木质画架 / 画板、素描纸、铅笔素描人像
素描元素：明暗排线、结构线、高光留白、铅笔笔触、素描纸纹理、擦笔痕迹
桌面道具：各种铅笔、橡皮、卷笔刀、炭笔、速写本、一杯咖啡
光线：柔和的工作室侧光，突出铅笔线条和人物的立体感

## 负面词补充
两个人物、两张脸、画框效果、漂浮感、完全脱离画纸、铅笔过渡不自然、画内人物与真人不一致、解剖错误、手指畸形、多余的手、塑料皮肤、CGI感、低清晰度、铅笔线条不流畅、2D和3D无质感差异
