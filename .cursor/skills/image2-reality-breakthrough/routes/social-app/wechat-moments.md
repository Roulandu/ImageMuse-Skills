# 朋友圈动态 App（虚构：友圈）

## 触发关键词
朋友圈、微信朋友圈、moments、pyq、从朋友圈里出来、朋友圈照片

## 视觉指纹
一部手机屏幕显示着社交动态分享类 App 界面，一条图文动态中的人物身体直接穿过屏幕玻璃，上半身以真实 3D 立体质感探出屏幕平面，下半身仍留在屏幕内以 2D 平面照片形式存在，界面有头像位、互动图标、评论区占位等社交动态元素，人物仿佛刚从朋友的动态里破壁而出。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身胸腔及肩部，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，明显高出屏幕玻璃平面
- 过渡融合区域：胸腔到腰腹位置与屏幕玻璃平面重合处，有界面元素重叠、透明度渐变和轻微的发光边框，仿佛人物正从 UI 界面中浮起
- 完全 2D 区域：屏幕内的腰以下部分，是社交动态照片中的 2D 平面影像，有手机屏幕的像素感、屏幕反光、轻微色温偏移，呈现明确的平面照片质感，无体积感
- 过渡方式：人物身体直接穿过手机屏幕玻璃平面，屏幕外为 3D 真人，屏幕内为同一人的 2D 社交动态照片，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质甜美日常，五官清秀自然，带点俏皮的笑容，像在跟你打招呼。

## 默认画幅
9:16 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
手持智能手机（无品牌标识，仅可见手机侧边一小部分）、社交动态类App界面（虚构品牌，与真实品牌无直接关联）
界面元素：用户头像位、昵称占位、发布时间图标、装饰性文字条（抽象色块替代具体文字）、九宫格或单图区域、心形点赞图标、评论气泡图标、底部导航图标
人物身体穿过屏幕平面，上半身探出，姿态自然放松
背景：温暖室内，轻微虚化
