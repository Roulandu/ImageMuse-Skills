# 社交 App 成真（social-app）

人物从社交媒体 App 界面中破壁而出的超现实人像路线，包括微信朋友圈、小红书、微博、抖音、快手、淘宝详情页六类主流社交与电商平台界面。

## 子路线表格

| 子路线 ID | 中文名 | 核心触发关键词 |
| --- | --- | --- |
| `wechat-moments` | 微信朋友圈 | 朋友圈、微信朋友圈、moments、pyq |
| `xiaohongshu` | 小红书 | 小红书、xiaohongshu、red note、小红薯 |
| `weibo` | 微博 | 微博、weibo |
| `douyin` | 短视频（闪拍） | 抖音、douyin、tiktok、短视频、视频号 |
| `kuaishou` | 快手 | 快手、kuaishou |
| `taobao` | 淘宝详情页 | 淘宝、taobao、详情页、商品页、宝贝详情 |

## 匹配规则

优先匹配更具体的关键词。当多个子路线关键词同时命中时，取最具体的 App 名称匹配结果。所有界面元素使用虚构名称替代，避免真实品牌侵权。
