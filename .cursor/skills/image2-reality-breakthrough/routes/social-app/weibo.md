# 微博客 App（虚构：微言）

## 触发关键词
微博、weibo、从微博里出来、热搜、博主照片、微博配图

## 视觉指纹
一部手机屏幕显示着微博客信息流类 App 界面，一条热门动态配图中的人物身体直接穿过屏幕玻璃，上半身以真实 3D 立体质感探出屏幕平面，下半身仍留在屏幕内以 2D 平面图片形式存在，界面有转发评论点赞图标、话题标签、头像位等信息流元素，人物像是从热搜里"走"出来了。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身胸腔，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，明显高出屏幕玻璃平面
- 过渡融合区域：胸腰交界处与屏幕玻璃平面重合处，有动态卡片边框发光、话题标签图标飘散和 @ 符号装饰飞出的效果
- 完全 2D 区域：屏幕内的腰以下部分，是微博客配图中的 2D 平面影像，有手机屏幕像素感、屏幕反光，呈现明确的平面图片质感，无体积感
- 过渡方式：人物身体直接穿过手机屏幕玻璃平面，屏幕外为 3D 真人，屏幕内为同一人的 2D 信息流配图，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质大方自信，五官明艳，表情带点从容的微笑，像一个拥有百万粉丝的人气博主。

## 默认画幅
9:16 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
智能手机（无品牌标识）立放、微博客类App界面（虚构品牌，与真实品牌无直接关联）
界面元素：用户头像位、昵称条、认证标识位、装饰性正文条（抽象色块替代具体文字）、配图区域、转发/评论/点赞图标及数字占位、话题标签图标、热搜入口位
人物身体穿过屏幕平面，上半身探出，一只手臂自然抬起做打招呼的姿态
光线：明亮的都市感光线
