# PS图层面板

## 触发关键词
PS图层、photoshop、图层面板、ps界面、从图层里出来、设计软件界面

## 视觉指纹
电脑屏幕上打开着图像处理软件，图层面板中的图层里的人物身体直接穿过图层平面，从小小的图层缩略图中放大破壁而出——身体的一部分仍在图层内以微缩 2D 平面形式存在，另一部分已经放大为真人大小的 3D 立体形态出现在软件界面前方，软件界面有工具栏、图层面板、调整面板。

## 过渡模板
- 完全 3D 区域：人物身体的前半部分（头部、肩颈、上半身），真人大小，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，明显在界面平面之前
- 过渡融合区域：身体穿过图层平面的位置，有图层蒙版渐变、像素边缘、选区蚂蚁线效果，像素点正在聚合为真实肌肤
- 完全 2D 区域：图层内的人物后半部分及界面背景，是 2D 平面 UI，包括图层列表、眼睛图标、不透明度、混合模式、工具栏、画布窗口、图层缩略图，呈现明确的平面 UI 质感，无体积感
- 过渡方式：人物身体从 PS 图层面板的图层缩略图中"放大破壁"而出，界面平面之前为真人大小的 3D 形态，图层之内为微缩的 2D 形态，以界面平面为分界面形成尺寸+质感的双重破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质创意时尚，五官个性鲜明，表情自信带点神秘，像一个被精心修出来的完美形象。

## 默认画幅
16:9 横版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
电脑屏幕图像处理软件界面（虚构软件名）
界面元素：工具栏、图层面板、属性面板、画布窗口、菜单、图层缩略图、蒙版缩略图
环境道具：数位板、触控笔、键盘鼠标
光线：屏幕冷光为主，科技感蓝紫色调
人物从图层面板中走出来
