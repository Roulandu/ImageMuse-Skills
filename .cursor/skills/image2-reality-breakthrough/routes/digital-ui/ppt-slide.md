# PPT幻灯片

## 触发关键词
PPT、幻灯片、powerpoint、slide、演示文稿、从PPT里出来、幻灯片人物

## 视觉指纹
一个投影屏幕或电脑屏幕上显示着PPT演示文稿，某一页幻灯片中的人物身体直接穿过幻灯片平面，上半身以真实 3D 立体质感从幻灯片中走出来，下半身仍留在幻灯片内以 2D 平面演示风格存在，PPT 的模板、图形和动画效果在过渡区域呈现，商务演示氛围。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理和职业装，有明确的体积感和光影层次，人物从幻灯片中"走出来"，明显在幻灯片平面之前
- 过渡融合区域：腰腹部与幻灯片平面重合处，有幻灯片切换效果、平滑过渡、图形元素飞出、渐变背景过渡
- 完全 2D 区域：幻灯片下半部分及腿部，是 2D 平面演示风格，有标题位（虚构）、副标题、图表、项目符号、模板设计、页码，呈现明确的平面设计质感，无体积感
- 过渡方式：人物身体直接穿过 PPT 幻灯片平面，幻灯片之前为 3D 真人，幻灯片之内为同一人的 2D 页面影像，以幻灯片平面为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质干练职业，五官端正精致，表情专业从容，像一个商务演示的主讲人。

## 默认画幅
16:9 横版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
会议室投影屏幕 / 电脑屏幕、PPT演示文稿（虚构主题）
PPT元素：标题页、副标题位、项目符号、图表图形、模板配色、页码、虚构公司logo位
环境道具：投影仪、会议桌、激光笔、笔记本电脑
光线：投影光 + 会议室灯光，商务场景
人物从幻灯片中跨步出来
