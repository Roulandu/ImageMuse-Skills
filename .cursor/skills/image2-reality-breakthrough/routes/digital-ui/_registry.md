# 数字界面成真（digital-ui）

人物从数字软件界面类媒介中破壁而出的超现实人像路线，包括网页弹窗、PS 图层面板、PPT 幻灯片、游戏加载界面、代码编辑器五类数字界面。

## 子路线表格

| 子路线 ID | 中文名 | 核心触发关键词 |
| --- | --- | --- |
| `webpage-popup` | 网页弹窗 | 网页、弹窗、webpage、popup、浏览器 |
| `photoshop-layers` | PS图层面板 | PS图层、photoshop、图层面板、ps界面 |
| `ppt-slide` | PPT幻灯片 | PPT、幻灯片、powerpoint、slide、演示文稿 |
| `game-loading` | 游戏加载界面 | 游戏加载、loading screen、游戏界面、加载画面 |
| `code-editor` | 代码编辑器 | 代码编辑器、code editor、ide、编辑器 |

## 匹配规则

优先匹配更具体的关键词。当多个子路线关键词同时命中时，取最具体的界面类型匹配结果。所有软件名称、游戏名称、品牌 Logo 使用虚构替代。
