# 装置场景成真（installation）

人物从实体装置与场景类媒介中破壁而出的超现实人像路线，包括霓虹灯牌、橱窗模特、镜子倒影、全息投影、立体贺卡五类装置场景。

## 子路线表格

| 子路线 ID | 中文名 | 核心触发关键词 |
| --- | --- | --- |
| `neon-sign` | 霓虹灯牌 | 霓虹灯、neon sign、霓虹牌、霓虹灯管 |
| `showcase-window` | 橱窗模特 | 橱窗、showcase、橱窗模特、玻璃橱窗 |
| `mirror-reflection` | 镜子倒影 | 镜子、mirror、倒影、镜中、镜面 |
| `hologram` | 全息投影 | 全息投影、hologram、全息、3D投影 |
| `popup-card` | 立体贺卡 | 立体贺卡、popup card、3D卡片、弹出卡 |

## 匹配规则

优先匹配更具体的关键词。当多个子路线关键词同时命中时，取最具体的装置类型匹配结果。所有品牌名称、商标使用虚构替代。
