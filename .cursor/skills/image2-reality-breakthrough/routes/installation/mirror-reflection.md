# 镜子倒影

## 触发关键词
镜子、mirror、倒影、镜中、镜面、从镜子里出来、镜中倒影、另一个自己

## 视觉指纹
一面华丽的镜子立在房间里，镜中的倒影人物身体直接穿过镜面平面，一部分身体已经走出镜子来到现实空间（3D 真人），另一部分还在镜子反射中（2D 镜像），镜子的边框、反射和玻璃质感在过渡区域精细呈现，镜像的神秘感和自我破壁主题。

## 过渡模板
- 完全 3D 区域：伸出镜子的手臂、头部和上半身前部，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，人物从镜子里"走出来"，身体前部明显在镜面之前
- 过渡融合区域：身体中线到镜面平面重合处，有镜像渐变、玻璃反光、银镜镀层效果，人物一半在镜内一半在镜外；镜框装饰贴附在镜子表面，被人物身体正确遮挡
- 完全 2D 区域：镜中的倒影后半部分及镜子本身，是反射效果，有镜面反射、镜框装饰、镜子厚度、镜中翻转的房间，呈现明确的平面镜像质感，有反射翻转
- 过渡方式：人物身体直接穿过镜面玻璃平面，镜子之前为 3D 真人实体，镜子之内为同一人的 2D 镜像倒影，以镜面玻璃为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质神秘双面，五官精致对称，表情镜里镜外一致，像一个人的破壁而出。

## 默认画幅
3:4 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
华丽镜框的镜子 / 全身镜（复古华丽风格）
镜子元素：雕花镜框、镜面反射、玻璃厚度、镜中房间倒影、轻微变形
房间环境：古典装修、吊灯、地毯、花瓶、窗帘
光线：柔和的室内光，镜面有高光反射
人物身体穿过镜面，从镜子里走出来
