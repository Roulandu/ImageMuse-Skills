# 平板屏幕

## 触发关键词
平板屏幕、从平板里出来、平板里、iPad、从平板里走出来、平板电脑、手绘板

## 视觉指纹
一块平板电脑平放在浅色大理石桌面上，屏幕显示一幅数字绘画，画中人物的身体直接穿过屏幕表面，上半身以真实 3D 立体质感坐立起来，下半身仍留在屏幕内以 2D 数字绘画形式存在，平板表面有触控笔触和光泽反射，人物与屏幕接触处有柔和的发光过渡。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理，人物坐在平板上方，有明确的体积感和光影层次
- 过渡融合区域：腰部到臀部与屏幕表面接触处，有柔和的光晕、像素渐变和数位笔触效果，仿佛人物正从数字绘画中凝聚成形
- 完全 2D 区域：屏幕内的腿部和下半身，是数位绘画风格的 2D 平面图像，有画笔笔触、图层透明度效果和数位板纹理，呈现明确的平面绘画质感，无体积感
- 过渡方式：人物身体直接穿过平板屏幕表面，屏幕上方为 3D 真人，屏幕内为同一人的 2D 数字绘画，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质文艺清新，五官柔和精致，眼神慵懒迷茫，像刚从画中醒来还没回过神。

## 默认画幅
4:3 横版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
浅色大理石桌面、平板电脑平放（无品牌标识）、触控笔斜放在旁边、咖啡杯、笔记本一角
屏幕内容：虚构的数位绘画作品、画笔工具栏图标、图层面板位、调色板图标（通用界面，不用真实软件名）
人物身体穿过屏幕平面，上半身立起
光线：柔和的室内自然光，屏幕轻微发光
