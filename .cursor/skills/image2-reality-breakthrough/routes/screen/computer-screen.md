# 电脑屏幕

## 触发关键词
电脑屏幕、显示器、从电脑里出来、computer screen、显示屏、从显示器里出来、桌面壁纸

## 视觉指纹
一张现代办公桌上放着一台宽屏显示器，屏幕亮着显示一张人物壁纸，壁纸中的人物身体直接穿过屏幕玻璃，上半身以真实 3D 立体质感探出屏幕平面，下半身仍留在屏幕内以 2D 桌面壁纸形式存在，屏幕边缘有蓝紫色的光晕和像素流动效果。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身胸腔及双臂，完全立体写实，真实皮肤纹理和衣物质感，手臂明显向前伸出屏幕玻璃平面
- 过渡融合区域：胸腔到腰腹位置与屏幕玻璃平面重合处，有像素化、扫描线和屏幕辉光效果，RGB 色彩分离，仿佛人物正在突破像素矩阵
- 完全 2D 区域：屏幕内的腰以下及腿部，是电脑壁纸中的 2D 平面图像，有像素网格、屏幕反光、色温偏冷，呈现明确的平面图像质感，无体积感
- 过渡方式：人物身体直接穿过电脑屏幕玻璃平面，屏幕外为 3D 真人，屏幕内为同一人的 2D 数字影像，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，五官精致立体，气质干练都市，眼神自信带点调皮，像一个从数字世界逃出来的精灵。

## 默认画幅
16:9 横版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
现代简约办公桌、宽屏显示器（无品牌标识）、机械键盘一角、鼠标、桌面小绿植、咖啡杯
屏幕界面：虚构的桌面壁纸界面、任务栏图标、桌面图标（通用样式，不用真实OS）
人物身体穿过屏幕平面，上半身前倾探出
光线：屏幕冷光 + 室内暖光，形成冷暖对比
