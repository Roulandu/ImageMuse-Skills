# 明信片

## 触发关键词
明信片、postcard、从明信片里出来、明信片人物、风景明信片

## 视觉指纹
一张复古明信片平放在木质桌面上，明信片上印着的人物身体直接穿过明信片纸面，上半身以真实 3D 立体质感坐起身来，下半身仍留在明信片内以 2D 印刷形式存在，明信片上的邮票、邮戳、手写痕迹围绕着她，温暖的午后阳光斜照在桌面上。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，人物上半身明显高出明信片纸面
- 过渡融合区域：腰部与明信片表面平面重合处，有纸张纤维纹理融入、复古色调渐变、明信片压痕边缘的效果
- 完全 2D 区域：明信片上的腰以下部分及风景背景，是平面印刷效果，有风景图案、邮票、邮戳、手写字迹位、横线（全部虚构，不用真实地名），呈现明确的平面印刷质感，无体积感
- 过渡方式：人物身体直接穿过明信片纸面平面，纸面之上为 3D 真人，纸面之内为同一人的 2D 印刷影像，以纸面为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质文艺复古，五官柔和温婉，眼神安静悠远，像一个从远方寄来的思念。

## 默认画幅
3:2 横版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
木质桌面、复古风光明信片（虚构风景地）
明信片元素：风景图案、邮票（虚构）、邮戳（虚构城市名）、手写字迹位、地址横线、明信片编号
桌面道具：钢笔、墨水、信封、干花、一杯茶
光线：温暖午后侧光，轻微的胶片质感
人物上半身从明信片中坐起，姿态自然
