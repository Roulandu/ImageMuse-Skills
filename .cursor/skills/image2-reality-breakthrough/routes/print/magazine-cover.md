# 杂志封面

## 触发关键词
杂志封面、magazine cover、杂志里、从杂志里出来、时尚杂志、封面女郎

## 视觉指纹
一本高端时尚杂志平放在大理石桌面上，封面人物的身体直接穿过杂志封面平面，以真实 3D 立体质感挺起，另一部分仍留在封面内以 2D 印刷人像形式存在，杂志封面标题、条形码、封面文案围绕着她，真实光影下杂志纸张有厚度和投影，形成"封面人物活了"的错觉。

## 过渡模板库

### 模板A：侧身滑出 + 纸张撕裂（默认推荐，时尚感强）
- 完全 3D 区域：头部、一侧肩、同侧手臂及上半身，以侧面角度从杂志封面中滑出坐起，身体呈优雅的 S 形对角线构图，真实皮肤纹理和高级妆容，有明确的体积感和光影层次
- 过渡融合区域：从肩部斜向延伸至髋部的斜线过渡带，杂志纸张被人物撕开一道不规则的斜向裂口，边缘有纸张撕裂的纤维毛边和微微翘起的卷边，印刷油墨在撕裂处晕染扩散；贴附在封面上的标题、条码、定价等印刷元素被人物身体正确遮挡；少量撕落的纸片和油墨颗粒从撕裂处飘散，主要分布在人物身后和侧面
- 完全 2D 区域：杂志封面内的另一侧身体及腿部，是平面印刷效果，有铜版纸光泽、印刷网点、封面标题、条码、定价，呈现明确的平面印刷质感，无体积感
- 过渡方式：人物侧身从杂志封面的撕裂缺口中滑出，封面之上为 3D 真人，封面之内为同一人的 2D 印刷人像，以纸面为分界面形成 2D→3D 破壁错觉

### 模板B：跪坐起身 + 纸张翘边
- 完全 3D 区域：头部、肩颈、上半身，人物从杂志封面中跪坐起身，一只手轻轻撑在封面纸面上（不碰边框），真实皮肤纹理和高级妆容，优雅自信的神态，有明确的体积感和光影层次
- 过渡融合区域：腰腹部与杂志封面平面重合处，封面纸张沿着人物身体边缘向上翘起翻卷，形成立体的纸边，有印刷网点渐变和纸张纹理融入皮肤的过渡效果，翘起的纸边投下细微的阴影；贴附在封面上的标题、条码、定价等印刷元素被人物身体正确遮挡，在翘起的纸边上随纸面一起翻卷
- 完全 2D 区域：杂志封面的下半部分及腿部，是平面印刷效果，有铜版纸光泽、印刷网点、封面标题、条码、定价，呈现明确的平面印刷质感，无体积感
- 过渡方式：人物从杂志封面中跪坐起身，纸张沿着身体边缘翘起翻卷，封面之上为 3D 真人，封面之内为同一人的 2D 印刷人像，以纸面为分界面形成 2D→3D 破壁错觉

### 模板C：迈步走出全身 + 时尚叙事
- 完全 3D 区域：头部、躯干、双臂及一条腿的大部分，已完全走出杂志封面，前脚已经踩在真实的大理石桌面上，重心在前脚，身体微微前倾呈迈步动态，高级时装的面料褶皱和垂坠感清晰分明，真实皮肤纹理和精致妆容
- 过渡融合区域：另一条腿的小腿和脚踝处与封面平面重合，有印刷网点渐变和纸张撕裂效果；贴附在封面上的封面标题、条码、定价等印刷元素被人物身体正确遮挡；身后飘散着少量撕落的杂志纸片和标题字母碎片，主要分布在身体后方和侧面的半空；裙摆和发梢还带着淡淡的印刷油墨残留
- 完全 2D 区域：杂志封面内的后脚及鞋履，是平面印刷效果，有铜版纸光泽、印刷网点，呈现明确的平面印刷质感，无体积感
- 过渡方式：封面女郎从杂志封面上迈步走下来，一只高跟鞋已经踏在真实的大理石桌面上，纸张在她脚踝处翻卷翘边，身后飘着撕碎的杂志纸片，以纸面为分界面形成 2D→3D 破壁错觉

### 模板D：伸手向前 + 印刷网点溶解
- 完全 3D 区域：一只手和前臂完全从封面中伸出，手指优雅地微曲，手部有真实皮肤纹理和精致的美甲，是画面的视觉焦点
- 过渡融合区域：手腕和前臂中部与杂志封面平面重合处，有印刷网点渐变、封面边框发光、油墨晕染效果，手的周围有印刷网点颗粒向四周飘散，主要分布在手臂周围和后方；贴附在封面上的标题、条码等印刷元素被人物手臂正确遮挡
- 完全 2D 区域：杂志封面内的身体其余部分（头部、躯干、另一条手臂、双腿），是平面印刷效果，有铜版纸光泽、印刷网点、封面标题、条码，呈现明确的平面印刷质感，无体积感
- 过渡方式：人物的一只手臂穿过杂志封面伸向观众，手和前臂为 3D 真人质感，身体其余部分仍在封面内为 2D 印刷人像，以纸面为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质高级冷艳，五官立体精致，眼神锐利自信，像一个国际大牌的封面超模。

## 默认画幅
3:4 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
大理石或木质桌面、高端时尚杂志平铺（虚构杂志名，不用真实品牌）
封面元素：虚构杂志标题、月份刊期、条形码、定价、封面故事标题位（抽象色块）、小号副标题位
桌面道具：咖啡杯、墨镜、口红、香水瓶小样
人物身体穿过封面平面，侧身或跪坐姿势，姿态优雅高级
光线：柔和的自然光，杂志纸张有真实反光
光影：破壁人物在桌面和杂志封面上投下真实的阴影，阴影边缘柔和，增强立体真实感
