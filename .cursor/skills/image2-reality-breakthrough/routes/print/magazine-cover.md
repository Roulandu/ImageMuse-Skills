# 杂志封面

## 触发关键词
杂志封面、magazine cover、杂志里、从杂志里出来、时尚杂志、封面女郎

## 视觉指纹
一本高端时尚杂志平放在大理石桌面上，封面人物的身体直接穿过杂志封面平面，上半身以真实 3D 立体质感挺起，下半身仍留在封面内以 2D 印刷人像形式存在，杂志封面标题、条形码、封面文案围绕着她，真实光影下杂志纸张有厚度和投影，形成"封面人物活了"的错觉。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理和高级妆容，有明确的体积感和光影层次，人物上半身明显高出封面纸面
- 过渡融合区域：腰腹部与杂志封面平面重合处，有印刷网点渐变、封面边框发光、杂志纸张纹理融入皮肤的过渡效果
- 完全 2D 区域：杂志封面的下半部分及腿部，是平面印刷效果，有铜版纸光泽、印刷网点、封面标题、条码、定价，呈现明确的平面印刷质感，无体积感
- 过渡方式：人物身体直接穿过杂志封面纸面平面，封面之上为 3D 真人，封面之内为同一人的 2D 印刷人像，以纸面为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质高级冷艳，五官立体精致，眼神锐利自信，像一个国际大牌的封面超模。

## 默认画幅
3:4 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
大理石或木质桌面、高端时尚杂志平铺（虚构杂志名，不用真实品牌）
封面元素：虚构杂志标题、月份刊期、条形码、定价、封面故事标题位（抽象色块）、小号副标题位
桌面道具：咖啡杯、墨镜、口红、香水瓶小样
光线：柔和的自然光，杂志纸张有真实反光
人物上半身从封面中微微抬起，姿态优雅

## 负面词补充
真实杂志品牌名、真实VOGUE/ELLE/BAZAAR logo、真实刊期条码、两个人物、两张脸、画框效果、手扶杂志边框、漂浮感、完全脱离杂志、印刷网点过渡不自然、封面内人物与真人不一致、解剖错误、手指畸形、多余的手、塑料皮肤、影楼感、低清晰度、2D和3D无质感差异
