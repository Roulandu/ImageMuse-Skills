# CD/磁带封面

## 触发关键词
CD封面、磁带、cd cover、cassette、唱片封面、从CD里出来、专辑封面

## 视觉指纹
一张CD唱片（或磁带）放在桌面上，封面的人物身体直接穿过CD封面平面，上半身以真实 3D 立体质感从CD盒中立体浮出来，下半身仍留在封面内以 2D 印刷形式存在，CD 的反光、塑料盒光泽和印刷网点在过渡区域清晰可见，旁边散落着歌词本和耳机。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，人物从 CD 封面中"站出来"，明显在封面平面之上
- 过渡融合区域：腰腹部与 CD 封面平面重合处，有印刷网点渐变、塑料盒反光、镭射光效果，仿佛人物正从塑料包装里出来
- 完全 2D 区域：CD 封面下半部分及腿部，是平面印刷效果，有专辑名位（虚构）、艺人名位（虚构）、曲目列表位、条形码、印刷网点，呈现明确的平面印刷质感，无体积感
- 过渡方式：人物身体直接穿过 CD/磁带封面平面，封面之上为 3D 真人，封面之内为同一人的 2D 印刷影像，以封面纸面为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质歌手明星范，五官精致上镜，表情自信有舞台感，像一个新晋歌手的首张专辑。

## 默认画幅
1:1 正方形构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
木质桌面 / 深色背景、CD塑料盒 + 封面（虚构专辑名）
封面元素：虚构专辑名位、虚构艺人名位、曲目列表位、唱片公司名（虚构）、条形码、印刷网点
桌面道具：耳机、歌词本、磁带几盒、唱片播放机一角
光线：柔和的侧光，CD塑料有反光和镭射效果
人物上半身从CD封面中挺起
