# 拍立得

## 触发关键词
拍立得、宝丽来、polaroid、拍立得照片、从拍立得里出来、一次成像

## 视觉指纹
一张刚显影的拍立得照片放在浅色桌面上，照片中的人物身体直接穿过相纸平面，上半身以彩色真实 3D 立体质感从相纸里探出来，下半身仍留在相纸内以 2D 显影中效果存在，照片还有显影中的渐变效果，相纸的白边和厚度清晰可见，温暖复古的色调环绕。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，人物从拍立得照片中"显影"出来，明显高出相纸平面
- 过渡融合区域：胸部到相纸表面平面重合处，有从显影中到完全写实的渐变，相纸的暖黄色调逐渐过渡到真实肤色，有颗粒感逐渐变清晰的效果
- 完全 2D 区域：照片下半部分及腿部，是拍立得效果，有显影中的斑驳感、胶片颗粒、暖黄色调、相纸白边，呈现明确的平面照片质感，无体积感
- 过渡方式：人物身体直接穿过拍立得相纸平面，相纸之上为 3D 真人，相纸之内为同一人的 2D 显影中影像，以相纸平面为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质甜美复古，五官圆润可爱，笑容灿烂温暖，像一张夏日旅行的拍立得记忆。

## 默认画幅
4:5 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
浅色桌面 / 浅色背景、拍立得相纸（有白边、有厚度）
拍立得元素：白边相纸、显影颗粒、暖黄色调、轻微漏光效果、相纸压痕
桌面道具：拍立得相机一角、其他几张拍立得散落、干花、帆布包一角
光线：温暖的午后阳光，轻微的胶片颗粒感
人物上半身从相纸中探出来笑
