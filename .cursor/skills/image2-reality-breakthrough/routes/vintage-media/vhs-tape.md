# VHS录像带

## 触发关键词
VHS、录像带、vhs tape、录影带、从录像带里出来、磁带、老录像

## 视觉指纹
一盘VHS录像带横放在深色桌面上，录像带封面上的人物身体直接穿过磁带封面平面，上半身以真实 3D 立体质感从磁带盒里走出来，下半身仍留在封面内以 2D VHS 画质效果存在，VHS 的画质失真、色彩偏移和磁噪在过渡区域与人物交织，旁边的老式录像机在转动。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，人物从录像带封面中"走出来"，明显在封面平面之上
- 过渡融合区域：腰腹部与磁带封面平面重合处，有 VHS 画质失真、色彩偏移、水平扫描线、磁噪颗粒的渐变效果
- 完全 2D 区域：录像带封面下半部分及腿部，是 VHS 风格平面效果，有低分辨率质感、色彩溢色、标题文字位（虚构电影名）、磁带标签贴纸，呈现明确的平面印刷+视频画质质感，无体积感
- 过渡方式：人物身体直接穿过 VHS 录像带封面平面，封面之上为 3D 清晰真人，封面之内为同一人的 2D VHS 低画质影像，以封面平面为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质复古性感，五官浓艳深邃，眼神神秘诱惑，像一部80年代B级片的女主角。

## 默认画幅
3:4 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
深色桌面 / 复古环境、VHS录像带（虚构电影名）
录像带元素：磁带标签、电影标题位（虚构）、录制日期、贴纸、磁带盒塑料质感
环境道具：录像机、电视机一角、遥控器、几盘录像带、爆米花桶
光线：昏暗室内 + 屏幕反光，VHS色调偏绿偏黄，轻微颗粒
人物上半身从录像带中前倾出来
