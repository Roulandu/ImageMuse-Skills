# Image2 结构化人像提示词

## 核心目标

把逐字段输入或自然语言需求整理成稳定、完整的中文人像摄影 Brief，再将其中真正影响可见画面的内容编译成精炼 Image2 提示词。Brief 保持 16 字段完整，最终 Prompt 不让所有字段等权争夺注意力。

## 工作流

1. 读取用户的逐字段输入或自然语言描述，识别并锁定所有安全、明确的值。
2. 读取 `../_shared/core/art-direction-engine.md`、`../_shared/core/spatial-photography-engine.md` 和 `../_shared/core/prompt-compiler.md`，围绕一个命题补全字段。
3. 先完成场景骨架、人物受力、机位与透视，再决定焦段、光线、色彩、材质与可见造型。
4. 读取 `../_shared/core/quality-gates.md`，在涉及年龄、真人、暴露、身体凝视或私密场景时再读取 `../_shared/references/adult-glamour-boundaries.md`。
5. 先输出固定字段清单作为完整 Brief，再按视觉优先级编译最终中文提示词；最后输出负面限制词和 3–6 个可选变化参数。
6. 默认只返回提示词文本。仅当用户明确说“直接出图”时，才进入图片生成流程；引用图或风格图本身不代表直接出图授权。

## 参数锁定与补全

- 原样保留用户明确给出的安全参数，不用默认值覆盖。
- 用户自定义身形时只使用自定义描述，不加入任何默认身形。
- 用户未指定画幅比例时使用 `9:16`。画幅始终包含：比例 + 方向描述（竖版/横版/正方形）+ 画质描述（超高清、高分辨率、细节清晰）+ 输出数量（生成1张独立图片，不要合并，不要拼图）；根据场景补充用途说明。参考 `../_shared/references/image2-canvas-parameters.md`。
- 其他缺失字段按已锁定主题补全，不把下方书店示例当作默认预设。
- 未指定人物身份时，在最终中文提示词中逐字使用主体常量 `原创成年东方女性，20岁及以上`；不要拆分、增字或同义改写。用户指定其他安全成年原创主体时使用其设定。
- 五官保持真实、有辨识度、非网红模板脸；摄影提示词保持真实皮肤、自然比例和合理解剖。
- 若用户输入之间互相矛盾，优先保留更具体的明确值，再调整自动补全部分；不要静默改写无冲突的锁定值。

## 身形与服装规则

- 用户明确指定身形时原样保留安全描述。
- 用户未指定时，根据动作、服装版型和镜头可见性补充中性、自然、比例协调的体态，不随机强加胸部或沙漏型描述。
- 只有用户明确要求强调身形，或任务属于服装试穿、礼服剪裁、Lookbook 等合身度展示时，才描述胸线、腰线、肩颈线、腰胯或腿部线条；始终使用完整服装和整体人物语境。
- 宽松外套、古装、制服、运动服或概念造型按真实版型处理，不为满足固定身形句而擅自增加收腰、腰封或贴身内搭。
- 按景别选择细节：不可见的下装、鞋袜、脚饰或配饰不写入最终 Prompt。

## 固定输出契约

所有用户可见内容使用简体中文。把下面的 `FIELD_LABELS` 视为不可改写的字面数组：

`FIELD_LABELS = [摄影风格, 写真方向, 场景方向, 服装方向, 气质标签, 五官方向, 五官细节, 发型方向, 身形方向, 线条强调, 镜头方向, 姿态动作, 光线氛围, 滤镜效果, 画幅比例, 补充要求]`

逐项复制 `FIELD_LABELS` 中的标签，只填写中文冒号后的值。严格按下列顺序输出，不从记忆重写字段名，不省略字段，不插入其他字段：

```text
摄影风格：...
写真方向：...
场景方向：...
服装方向：...
气质标签：...
五官方向：...
五官细节：...
发型方向：...
身形方向：...
线条强调：...
镜头方向：...
姿态动作：...
光线氛围：...
滤镜效果：...
画幅比例：...
补充要求：...

最终中文提示词：
...

负面限制词：
...

可选变化参数：
- ...
- ...
- ...
```

16 个字段构成完整 Brief。最终中文提示词必须保留所有用户锁定值，但只选择影响可见画面、身份一致性、摄影因果或交付用途的补全信息；按 `prompt-compiler.md` 重排，不逐项复述字段。「发型方向」可参考 `../_shared/knowledge/hairstyles.md`。负面限制词应简洁且与任务相关。可选变化参数只改变未锁定的色调、镜头、材质、场景细节、姿态或画幅。

## 质量检查

输出前逐项确认：

- 16 个字段名称、数量和顺序完全一致。
- 将输出字段名与 `FIELD_LABELS` 逐项精确比较；若出现已知近似错误 `写实方向` 或 `拍摄方向`，替换为 `写真方向`，其他不一致标签也必须按数组修正后再返回。
- 身形缺失时使用中性自然体态；非合身度展示任务不自动强调胸腰曲线。
- 最终提示词明确是原创成年人物，覆盖全部已锁定参数，但不机械复述全部补全字段。
- 构图、机位、透视、受力、遮挡、光源和投影能够同时成立。
- 有一个第一阅读焦点、一个次要线索和克制余味；删除至少一个无职责元素。
- 画面表现为整体人像摄影，不把胸、腰、臀或其他身体局部作为独立焦点。
- 场景、动作、镜头与光线在现实中能够同时成立；无未授权真人相似、幼态、偷拍、露骨或非自愿语境。

## 完整示例：冷白 CCD 书店生活照

```text
摄影风格：冷白清透CCD生活照风
写真方向：知性室内生活照
场景方向：现代书店阅读区 / 白色书架 / 浅木桌 / 大面积落地窗
服装方向：湖蓝色修身针织上衣 + 米白色高腰包臀中裙
气质标签：知性、清冷、安静、温柔、干净
五官方向：真实清冷淡颜，干净高级，不网红
五官细节：偏窄鹅蛋脸，轮廓利落但柔和；清亮杏眼，眼神安静克制；鼻梁清秀流畅；唇形自然克制，低饱和裸粉唇色
发型方向：黑色长发低扎或自然披散，脸侧少量碎发，整体利落干净
身形方向：自然匀称体态，与弯腰找书动作和针织服装版型协调
线条强调：以肩背转折和手臂动作线为主，不强调不可见的身体局部
镜头方向：相机位于胸口高度、距人物约2米，50mm半身到大腿构图；书架单点透视汇向人物手部，人物右侧保留视线空间
姿态动作：左脚承重站在书架侧前方，身体朝书架、头部轻微回转；右手刚抽出半本书，书脊与手指存在真实接触
光线氛围：左侧落地窗为动机主光，书架白色漫反射轻补暗部，人物比背景亮约半档，阴影方向与窗光一致
滤镜效果：冷白主色域、木色从属色、湖蓝上衣为单一强调色；轻颗粒，保留皮肤和针织纤维
画幅比例：9:16竖版构图，超高清，高分辨率，细节清晰
补充要求：视觉命题为“井然书架与一次被打断的阅读之间的安静张力”；背景只保留白色书架、浅木桌和落地窗三个环境信号

最终中文提示词：
9:16 竖版，超高清、高分辨率，生成1张独立图片，不合并、不拼图。原创成年东方女性，20岁及以上，在井然书架与一次被打断的阅读之间停住：左脚承重站在书架侧前方，身体朝向书架，头部轻微回转，右手刚抽出半本书，书脊与手指保持真实接触。胸口高度机位距人物约2米，50mm半身到大腿构图，书架单点透视汇向手部，人物右侧保留视线空间；眼睛与手部清晰，背景书脊轻微失焦。左侧落地窗作为动机主光，白色书架只提供柔和反射补光，人物比背景亮约半档。冷白环境占主导，浅木色从属，湖蓝针织上衣成为唯一强调色；保留自然皮肤、低扎黑发碎发和针织纤维，米白中裙只呈现镜头内可见结构。背景仅保留白色书架、浅木桌和落地窗三个信号，轻颗粒，不使用无职责装饰。

负面限制词：
未成年感、学生元素、真实人物相似、网红模板脸、身体局部特写、低机位身体凝视、露骨表达、过度磨皮、塑料皮肤、解剖错误、手指畸形、水印、乱码文字

可选变化参数：
- 发型改为利落低马尾
- 镜头改为 50mm 平视三分之四身
- CCD 颗粒强度轻微增加
```

示例仅说明输出结构和完成度。处理其他主题时，根据用户输入重新生成全部字段，不复用书店、湖蓝服装或冷白 CCD 内容。
