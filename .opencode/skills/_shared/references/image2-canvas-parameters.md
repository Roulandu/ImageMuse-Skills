# Image2 画布与输出参数

Use this reference when building Image2 final prompts to ensure stable, controllable output. Covers five categories: aspect ratio, orientation, resolution/image quality, image count, and output format/purpose.

## 1. 画面比例

| 比例 | 适合场景 | 推荐写法 |
| --- | --- | --- |
| **1:1** | 头像、商品图、社交媒体方图 | `1:1 正方形` |
| **3:4** | 人像写真、海报、小红书封面 | `3:4 竖版` |
| **4:3** | 摄影、插画、传统屏幕 | `4:3 横版` |
| **2:3** | 全身人像、摄影海报 | `2:3 竖版` |
| **3:2** | 相机照片、横版摄影 | `3:2 横版` |
| **9:16** | 手机壁纸、抖音、短视频首帧 | `9:16 竖版` |
| **16:9** | 视频封面、电影画面、电脑壁纸 | `16:9 横版` |
| **21:9** | 超宽电影画幅、场景概念图 | `21:9 超宽画幅` |

常用场景推荐：

- 人物写真：**3:4**
- 手机动态壁纸、短视频：**9:16**
- 电影级场景、视频素材：**16:9**
- 小红书封面：通常 **3:4**
- 头像：**1:1**

比例表示的是画布形状，不等于人物占比。

## 2. 横竖方向

比例之外，最好同时指定方向，比只写比例更稳定：

- `竖版构图`
- `横版构图`
- `正方形构图`
- `超宽银幕构图`
- `手机全屏竖版`
- `电影级宽画幅`

示例：`16:9横版，电影级宽画幅，人物位于画面右侧三分之一。`

## 3. 分辨率与画质

在提示词里可以写：

- `高清`
- `超高清`
- `高分辨率`
- `4K质感`
- `8K细节`
- `3840×2160`
- `2160×3840`

注意：提示词里的"4K、8K"主要是画质和细节要求，并不一定表示最终文件会严格输出对应像素。ChatGPT 会根据当前图像模型选择实际输出尺寸。

因此比较可靠的写法是：

> 9:16竖版，超高清，高分辨率，细节清晰，适合手机全屏显示。

而不是只写：

> 2160×3840。

## 4. 图片数量

可以指定：

- `生成1张`
- `生成2张独立图片`
- `生成4个版本`
- `每个人单独生成一张`
- `不要拼图，不要合并`
- `依次单独输出`

批量人物图片时，建议写得非常明确：

> 共生成8张图片，每张仅出现1个人物，人物分别单独输出，不要九宫格，不要拼接，不要合并。

默认（用户未指定数量时）：生成1张独立图片。

## 5. 输出格式与用途

在普通聊天生图中，一般不必指定 JPG、PNG 或 WebP，可以表达用途：

- `适合透明PNG`
- `适合后期抠图`
- `适合印刷`
- `适合手机壁纸`
- `适合视频首帧`
- `适合作为人物参考图`

## 推荐的画布参数模板

最终中文提示词开头应包含画布参数段。使用以下结构（按需要取舍）：

```
【画布参数】
{比例}{方向}构图，{画质描述}，{用途或输出格式说明}。
【输出要求】
生成{数量}张独立图片，不要合并，不要九宫格。
```

示例（人像写真默认）：

```
【画布参数】
3:4竖版构图，超高清，高分辨率，细节清晰，适合人像写真。
【输出要求】
生成1张独立图片，不要合并，不要拼图。
```

完整示例（电影场景）：

```
【画布参数】
21:9超宽银幕构图，电影级宽画幅，4K质感，高分辨率，适合电影场景概念图。
【输出要求】
生成1张独立图片，不要合并，不要拼图。
```

## 默认值规则

当用户未指定以下参数时，按场景补全默认值（标注为补充默认值）：

- **比例**：人像写真类默认 `3:4`；手机壁纸/短视频类默认 `9:16`；电影/视频素材类默认 `16:9`；头像/商品类默认 `1:1`；海报封面类根据版式选 `2:3` 或 `3:4`。
- **方向**：与比例一致的方向描述（竖版/横版/正方形/超宽银幕）。
- **画质**：`超高清，高分辨率，细节清晰`。
- **数量**：`生成1张独立图片，不要合并，不要拼图`。
- **用途/格式**：根据场景推导，如人像写真题材写"适合人像写真展示"。
