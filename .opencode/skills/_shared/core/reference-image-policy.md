# Reference Image Policy

Use a reference image only with the user's authorisation. Before using it, declare and lock its role in the parameter-lock record: for example composition, pose, clothing silhouette, lighting, scene, palette, or an authorised subject reference.

Do not infer permission to copy a face, identity, celebrity, private person, brand, or copyrighted character merely because an image was supplied. Keep the role limited to the authorised elements, do not let it override higher-precedence safety rules, and avoid unrequested identity transfer. If no role is authorised, ask for one or proceed without the image.
