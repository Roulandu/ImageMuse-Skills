# Image2 Reality Breakthrough

## 技能定位

本技能用于生成「人物从 2D 媒介破壁进入现实世界」的超现实人像摄影提示词。核心是制造 2D 平面内容与 3D 真实人物在同一画面中的过渡错觉，人物身体的一部分留在媒介内，另一部分突破媒介表面进入现实空间，形成强烈的视觉冲击感。

**做什么：**
- 八大媒介路线：纸上成真、屏幕成真、社交 App、印刷品、艺术画作、复古媒介、数字界面、装置场景
- 提供子路线级别的视觉指纹、过渡模板、场景道具、负面词补充
- 输出合同级中文提示词，含破壁设定卡与过渡效果描述

**不做什么：**
- 不生成纯 2D 插画、纯屏幕截图、纯平面设计稿
- 不生成未成年、不露骨、不用真人/真品牌/真角色名
- 不生成暴力、血腥、恐怖主题的破壁内容

## 工作流

1. 加载核心契约文件（按 Required load order 所列顺序）
2. 解析用户输入，锁定安全参数（根据 `parameter-schema.md`）
3. 识别大路线（8 选 1）：匹配成功则进入步骤 4；匹配失败则返回 8 个大路线选项供用户选择
4. 加载大路线 `./routes/{routeId}/_registry.md`
5. 识别子路线：匹配成功则进入步骤 6；匹配失败则返回该大路线下所有子路线选项
6. 加载子路线文件 `./routes/{routeId}/{subRouteId}.md`，获取视觉指纹、过渡模板、默认主体、默认画幅、场景道具、负面词补充
7. 检查图片风格（iPhone 直出 / 单反质感）：未指定则让用户二选一
8. 组装输出契约（按 `output-contract.md` 规定的格式）
9. 应用质量门（通用质量门 + 破壁专项质量门）
10. 返回结果

## 分步交互规则

以下三种未完成状态，仅返回对应选择项，不生成最终提示词：

- **路线未选**（大路线缺失）：返回 8 大路线的中文名 + 一句话简介，供用户选择
- **子路线未选**（大路线已选、子路线缺失）：返回该大路线下所有子路线的中文名 + 核心触发关键词，供用户选择
- **图片风格未选**（路线已选、子路线已选、图片风格缺失）：返回图片风格二选一选项

## 子路线文件格式说明

每个子路线文件包含以下 7 个字段：

1. **触发关键词**：用于匹配用户输入的关键词列表
2. **视觉指纹**：该子路线独有的视觉特征、材质、色彩、质感描述
3. **过渡模板**：破壁过渡的标准写法模板，描述人物如何从媒介中突破出来
4. **默认主体气质**：适配该子路线的默认人物气质描述
5. **默认画幅**：推荐的画幅比例与方向
6. **场景与道具**：配合破壁效果的背景环境与道具元素
7. **负面词补充**：该子路线特有的负面限制词补充

## 默认值与覆盖规则

- **主体默认**：`25岁左右的中国青年，五官精致立体，气质自然真实。`
- **主体覆盖**：用户指定安全主体时，完全替换默认主体描述
- **画幅默认**：`3:4竖版构图，超高清，高分辨率，细节清晰`；子路线有指定画幅时优先使用子路线画幅
- **画幅覆盖**：用户指定画幅时，以用户指定为准
- **图片风格默认**：无默认值，必须由用户二选一
- **图片风格覆盖**：用户指定其他安全风格时，使用用户风格描述
- **服装默认**：根据子路线默认主体气质搭配得体服装
- **服装覆盖**：用户指定安全服装时，保留用户方向并完善描述

## 破壁专项质量门

在通用质量门基础上，额外检查以下 6 条：

1. **过渡自然**：媒介内 2D 部分与破壁 3D 部分的过渡边界自然可信，撕裂/褶皱/光影过渡合理，无生硬切割感
2. **人物一致**：媒介内的 2D 人物与破壁而出的 3D 人物是同一个人，五官、发型、服装、配饰完全一致
3. **物理接触真实**：破壁人物与现实场景有真实的物理接触——接触阴影、压痕、支撑关系明确，无漂浮感
4. **比例协调**：破壁人物与媒介、与现实环境的比例关系协调，透视正确，无尺度违和
5. **媒介内容可信**：媒介内的画面内容符合该媒介的真实特征（分辨率、印刷网点、像素格、笔触等），不出现跨媒介错位
6. **无品牌侵权风险**：媒介中不出现真实品牌 Logo、真实杂志名、真实 App 界面、真实角色名，使用虚构替代

## 输出契约

完整模式（`outputMode: complete`）按以下顺序输出：

1. **意图摘要**
2. **已锁定参数**
3. **破壁设定卡**（大路线名、子路线名、过渡类型、媒介特征、破壁方向、物理接触方式）
4. **最终中文提示词**
5. **负面限制词**
6. **可选变化参数**

简洁模式（`outputMode: concise`）：仅返回「最终中文提示词」+「负面限制词」。

直接出图门：仅当用户说「直接出图」且交互模式为 `direct-image` 时生成图片，其他情况均返回文本。

## 图片风格二选一

用户未指定图片风格时，必须让用户从以下两个字面常量中选择一个：

1. `整张照片必须呈现着iPhone手机直出的拍摄质感，不要出现AI痕迹，不要过度磨皮，不要美颜滤镜`
2. `整张照片必须呈现着专业单反相机的写真拍摄质感，不要出现AI痕迹，不要过度磨皮，不要过度美颜滤镜`

## 负面限制词组成

最终负面限制词 = 通用负面词 + 破壁专项负面词 + 子路线补充负面词

- **通用负面词**：见 `../_shared/core/quality-gates.md` 相关约束
- **破壁专项负面词**：过渡生硬、人物不一致、漂浮感、比例失调、透视错误、媒介内容失真、品牌 Logo、真实杂志名、真实 App 界面
- **子路线补充负面词**：见各子路线文件

## 可选变化参数

提供 6 个维度的变化建议：

1. **过渡程度**：轻微探出 / 半身破壁 / 全身走出
2. **姿势**：正面 / 侧身 / 回眸 / 动态奔跑
3. **画幅**：竖版 3:4 / 横版 16:9 / 正方形 1:1
4. **光线**：自然光 / 侧光硬影 / 逆光轮廓 / 冷暖对比
5. **服装**：休闲日常 / 正装 / 运动风 / 国风
6. **媒介风格**：同一路线下可微调媒介的年代感、色彩倾向、磨损程度

## 边界与红线

- 不生成未成年人物，不使用幼态、学生、青春校园等 cues
- 不露骨、不性化、不身体局部凝视、不低机位身体角度
- 不用真人姓名、真实名人相似、真实角色名、真实 IP
- 不用真实品牌名、真实杂志名、真实 App 名称与界面
- 不生成暴力、血腥、恐怖、猎奇主题
- 破壁效果以审美和创意为导向，不制造惊悚或不适感
