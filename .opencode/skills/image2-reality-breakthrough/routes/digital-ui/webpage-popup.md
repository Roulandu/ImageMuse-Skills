# 网页弹窗

## 触发关键词
网页、弹窗、webpage、popup、浏览器、从网页里出来、网站弹窗广告

## 视觉指纹
一个电脑浏览器窗口打开着网页，弹窗广告中的人物身体直接穿过弹窗平面，上半身以真实 3D 立体质感从弹窗中探出身来，下半身仍留在弹窗内以 2D 平面 UI 形式存在，网页元素有按钮、关闭叉号、装饰图形，人物像是从弹窗广告里"跳出来"挡在你的屏幕前。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，人物从弹窗中探出，明显在弹窗平面之前
- 过渡融合区域：腰腹部与弹窗平面重合处，有 UI 元素重叠、半透明效果、窗口边框发光、网页像素化过渡
- 完全 2D 区域：弹窗内部和网页背景中的下半身，是 2D 平面 UI，包括弹窗标题栏、关闭按钮（X）、广告文案位、图片区域、CTA 按钮、浏览器标签栏，呈现明确的平面 UI 质感，无体积感
- 过渡方式：人物身体直接穿过网页弹窗广告平面，弹窗之前为 3D 真人，弹窗之内为同一人的 2D 广告影像，以弹窗平面为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质甜美亮眼，五官精致，表情热情带点夸张，像一个弹窗广告里的促销模特。

## 默认画幅
16:9 横版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
电脑屏幕浏览器界面（虚构网站，不用真实品牌）
网页元素：浏览器标签栏、地址栏、网页内容区、弹窗广告、关闭按钮（X）、文案区域、立即购买按钮
光线：屏幕冷光 + 室内环境光，画面有显示器质感
人物上半身从弹窗中探出来，姿态引人注目
