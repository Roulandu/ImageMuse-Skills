# 代码编辑器

## 触发关键词
代码编辑器、code editor、ide、编辑器、从代码里出来、程序员、代码生成

## 视觉指纹
一个代码编辑器窗口里显示着代码，由代码生成的人物身体直接穿过编辑器窗口平面，上半身以真实 3D 立体质感从编辑器窗口里浮现出来，下半身仍留在编辑器内以 2D 代码粒子形式存在，代码行、语法高亮、光标闪烁在过渡区域流动，人物像是被代码"编译"出来的形象。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，人物从代码中"生成"出来，明显在编辑器平面之前
- 过渡融合区域：腰腹部与编辑器平面重合处，有代码行流动、粒子像素、语法高亮色彩、光标闪烁的渐变效果；贴附在编辑器界面上的代码行、行号、标签页、侧边栏等UI元素被人物身体正确遮挡；少量代码粒子从过渡区域飘散，主要在人物身后和侧面
- 完全 2D 区域：代码编辑器界面中的下半身和代码，是 2D 平面 IDE，有代码行、语法高亮、行号、侧边栏、标签页、终端窗口，呈现明确的平面代码质感，无体积感
- 过渡方式：人物身体直接穿过代码编辑器窗口平面，编辑器之前为 3D 真人，编辑器之内为同一人的 2D 代码粒子形态，以编辑器平面为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质科技极客，五官清秀聪明，表情专注灵动，像一个由AI生成的虚拟程序员。

## 默认画幅
16:9 横版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
电脑屏幕代码编辑器界面（虚构IDE）
编辑器元素：代码行、语法高亮颜色、行号、侧边文件树、标签页、终端、光标闪烁
环境道具：机械键盘、多屏显示器、咖啡杯、桌面小摆件
光线：屏幕冷蓝光 + 暖色台灯，程序员深夜氛围
人物从代码中浮现出来
