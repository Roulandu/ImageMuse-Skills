# 复古媒介成真（vintage-media）

人物从复古媒介类载体中破壁而出的超现实人像路线，包括宝丽来拍立得、胶片底片、CRT 显像管老电视、CD 磁带封面、VHS 录像带五类复古媒体。

## 匹配规则

优先匹配更具体的关键词。当多个子路线关键词同时命中时，取最具体的媒介类型匹配结果。所有唱片名称、节目名称使用虚构替代。
