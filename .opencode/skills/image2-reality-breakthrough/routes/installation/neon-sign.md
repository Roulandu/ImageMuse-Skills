# 霓虹灯牌

## 触发关键词
霓虹灯、neon sign、霓虹牌、霓虹灯管、从霓虹灯里出来、neon、霓虹招牌

## 视觉指纹
夜晚的城市街道上，一块霓虹招牌发着光，霓虹灯管组成的人物造型身体直接穿过霓虹牌平面，上半身以真实 3D 立体质感从霓虹灯中走出来，下半身仍留在霓虹牌内以 2D 霓虹灯管轮廓形式存在，霓虹灯管的光晕、色彩辉光和电流感在过渡区域环绕，赛博朋克氛围拉满。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理，有明确的体积感和光影层次，人物从霓虹灯牌中"走出来"，明显在霓虹牌平面之前
- 过渡融合区域：腰胯部与霓虹灯牌平面重合处，有霓虹光边、色彩溢出、电流粒子、光晕扩散的效果，霓虹色彩映在人物皮肤上；贴附在霓虹牌上的灯管造型、电极、支架等元素被人物身体正确遮挡；少量电流粒子从过渡区域飘散，主要在人物身后和侧面
- 完全 2D 区域：霓虹灯牌中的下半身及造型本身，是霓虹灯管组成的 2D 平面造型，有玻璃管、电极、发光气体、金属背板、安装支架，呈现明确的平面霓虹灯管质感，无体积感
- 过渡方式：人物身体直接穿过霓虹灯牌平面，霓虹牌之前为 3D 真人，霓虹牌之内为同一人的 2D 霓虹灯管造型，以霓虹牌平面为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质赛博朋克，五官冷艳立体，眼神魅惑神秘，像一个霓虹城市里的夜间精灵。

## 场景与道具
夜晚城市街区、霓虹灯牌（虚构店名）
霓虹元素：发光灯管、电极、金属支架、电线、变压器、彩色玻璃、光晕辉光
城市环境：砖墙、其他霓虹招牌、雨后湿滑路面、雾气、远处建筑轮廓
光线：霓虹彩光为主，高饱和度蓝紫红，夜晚对比强烈
人物从霓虹牌中跨步出来
