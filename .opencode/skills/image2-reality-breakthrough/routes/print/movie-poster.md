# 电影海报

## 触发关键词
电影海报、poster、电影海报里出来、从海报里出来、海报人物、电影角色

## 视觉指纹
一张电影海报贴在砖墙或装在画框里，海报中的人物身体直接穿过海报平面，上半身以真实 3D 立体质感向前探出，下半身仍留在海报内以 2D 印刷形式存在，海报上的电影标题、演员名单、上映日期等元素围绕着她，真实光线在海报边缘和人物身上形成自然的光影过渡。

## 过渡模板
- 完全 3D 区域：头部、肩颈、上半身，完全立体写实，真实皮肤纹理和电影级妆容，有明确的体积感和光影层次，明显在海报平面之前
- 过渡融合区域：腰胯部与海报平面重合处，有印刷质感渐变、海报色彩边缘融入的效果；贴附在海报表面的电影标题、演员名单、上映日期等印刷元素被人物身体正确遮挡；少量油墨颗粒和文字碎片从过渡区域飘散，主要在人物身后和侧面
- 完全 2D 区域：海报下半部分及腿部，是平面印刷海报，包括电影标题、虚构演员名单、上映日期、评分、宣传语（全部虚构，不用真实电影名），呈现明确的平面印刷质感，无体积感
- 过渡方式：人物身体直接穿过海报画面平面，海报之前为 3D 真人，海报之内为同一人的 2D 印刷影像，以海报纸面为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质电影感强，五官大气有故事感，眼神深邃有戏，像一个文艺片女主角。

## 默认画幅
2:3 竖版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
砖墙背景 / 画框中的电影海报、电影风格海报设计（虚构电影名）
海报元素：虚构电影标题、主演名单位、导演名、上映日期、宣传语、评分星级
光线：电影感侧光，高对比度，有海报光源与真实光源的融合感
人物身体穿过海报平面，上半身微微向前探出
