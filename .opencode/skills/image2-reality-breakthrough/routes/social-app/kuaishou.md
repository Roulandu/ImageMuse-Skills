# 短视频 App（虚构：快映）

## 触发关键词
快手、kuaishou、从快手里出来、老铁、短视频平台

## 视觉指纹
一部手机竖屏显示着短视频社区类 App 界面，一个生活类短视频中的人物身体直接穿过屏幕玻璃，以真实 3D 立体质感探出屏幕平面，另一部分仍留在屏幕内以 2D 视频画面形式存在，界面有互动图标列、关注按钮、底部导航等短视频元素，人物像是从日常视频里"走"出来跟你打招呼。

## 过渡模板库

### 模板A：俯身探出头 + 斜向切面（默认推荐，亲切感强）
- 完全 3D 区域：头部、一侧肩颈、上半身胸腔及同侧手臂，人物俯身从屏幕中探出，挥手打招呼的姿态，真实皮肤纹理，自然生活化的妆容和表情，有明确的体积感和光影层次
- 过渡融合区域：从一侧肩部斜向延伸至对侧腰部的斜线切面与屏幕平面重合处，有视频播放进度条的光带效果和界面透明度渐变；贴附在屏幕表面的点赞红心、评论气泡、关注按钮等界面元素被人物身体正确遮挡；少量细小图标从过渡区域飘散，主要在人物身后
- 完全 2D 区域：屏幕内的另一侧身体及腰以下部分，是短视频画面中的 2D 平面影像，有视频画面质感、屏幕像素网格、轻微色温偏移，呈现明确的视频画面平面感，无体积感
- 过渡方式：人物俯身从短视频屏幕中斜向探出上半身，屏幕外为 3D 真人，屏幕内为同一人的 2D 短视频画面，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板B：迈步走出全身 + 生活场景
- 完全 3D 区域：头部、躯干、双臂及一条腿的大部分，已完全走出屏幕，前脚已经踏入现实，重心在前脚，身体微前倾呈行走动态，自然的生活穿搭，真实皮肤纹理、服装面料褶皱清晰分明
- 过渡融合区域：另一条腿的小腿处与屏幕平面重合，有视频帧叠影溶解效果、进度条光带；贴附在屏幕上的点赞红心和评论气泡被人物身体正确遮挡；少量互动图标从人物身后飘散飞出，分布在身体后方和侧面的半空；发梢和裙摆还拖着视频帧的残影
- 完全 2D 区域：屏幕内的后脚及鞋履，是短视频画面中的 2D 平面影像，有视频画面质感、屏幕像素网格、轻微色温偏移，呈现明确的视频画面平面感，无体积感
- 过渡方式：人物从短视频 App 中迈步走出，一只脚已踏入现实，身后拖着视频帧残影和飘散的互动图标，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板C：伸手向前 + 视频扫描线
- 完全 3D 区域：一只手和前臂完全伸出屏幕，手指做"双击点赞"的手势，手部有真实皮肤纹理和体积感，是画面的视觉焦点
- 过渡融合区域：手腕和前臂中部与屏幕玻璃平面重合处，有视频播放进度光带效果、视频扫描线和轻微的像素溶解效果；贴附在屏幕表面的点赞红心、关注按钮等被人物手臂正确遮挡；少量细小图标和像素粒子从过渡区域飘散，主要在手臂后方
- 完全 2D 区域：屏幕内的身体其余部分（头部、躯干、另一条手臂、双腿），是短视频画面中的 2D 平面影像，有视频画面质感、屏幕像素网格、轻微色温偏移，呈现明确的视频画面平面感，无体积感
- 过渡方式：人物的一只手臂穿过短视频屏幕伸向观众，手和前臂为 3D 真人质感，身体其余部分仍在屏幕内为 2D 视频画面，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板D：玻璃碎裂飞溅 + 仰身冲出
- 完全 3D 区域：头部、肩颈、上半身及双臂，完全立体写实，真实皮肤纹理，头发和衣物向后飞扬有动感，笑容灿烂有感染力，有明确的体积感和光影层次
- 过渡融合区域：胸肩区域周围的屏幕玻璃呈放射状碎裂，多块大小不一的玻璃碎片飞溅悬浮在空中，主要分布在人物身后和身体两侧；贴附在屏幕上的点赞红心、关注按钮、评论气泡等短视频元素被人物身体正确遮挡，部分从碎片间隙中可见；极少数细小碎片飞近镜头形成前景虚化效果，不遮挡面部
- 完全 2D 区域：屏幕内的腰以下部分，是短视频画面中的 2D 平面影像，透过未碎裂的屏幕区域可见，有视频画面质感和屏幕像素网格，呈现明确的视频画面平面感，无体积感
- 过渡方式：人物冲破短视频屏幕玻璃，玻璃呈放射状碎裂飞溅，人物从碎裂缺口中冲出，屏幕外为 3D 真人，屏幕内为同一人的 2D 短视频画面
