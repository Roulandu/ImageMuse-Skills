# 平板屏幕

## 触发关键词
平板屏幕、从平板里出来、平板里、iPad、从平板里走出来、平板电脑、手绘板

## 视觉指纹
一块平板电脑平放在浅色大理石桌面上，屏幕显示一幅数字绘画，画中人物的身体直接穿过屏幕表面，以真实 3D 立体质感立起，另一部分仍留在屏幕内以 2D 数字绘画形式存在，平板表面有触控笔触和光泽反射，人物与屏幕接触处有柔和的发光过渡。

## 过渡模板库

### 模板A：跪坐起身 + 波动涟漪（默认推荐，文艺感强）
- 完全 3D 区域：头部、肩颈、上半身，人物从平板屏幕中跪坐起身，双手轻轻撑在屏幕表面（不碰边框），真实皮肤纹理，慵懒迷茫的神态，有明确的体积感和光影层次
- 过渡融合区域：腰部到臀部与屏幕表面接触处，屏幕表面像水面一样产生波纹涟漪，数字绘画随波纹扭曲变形，柔化的边缘有柔和的光晕和数位笔触渐变效果；贴附在屏幕上的工具栏图标、调色板等UI元素被人物身体正确遮挡，随波纹一起扭曲
- 完全 2D 区域：屏幕内的腿部和下半身，是数位绘画风格的 2D 平面图像，有画笔笔触、图层透明度效果和数位板纹理，被涟漪扭曲变形，呈现明确的平面绘画质感，无体积感
- 过渡方式：人物从平板屏幕的涟漪波纹中跪坐起身，屏幕上方为 3D 真人，屏幕内为同一人的 2D 数字绘画，以屏幕玻璃为分界面形成柔美的 2D→3D 破壁错觉

### 模板B：像素溶解 + 侧身滑出
- 完全 3D 区域：头部、一侧肩、同侧手臂及上半身，以侧面角度从平板屏幕中滑出坐起，身体呈优雅的对角线构图，真实皮肤纹理，文艺清新的气质，有明确的体积感和光影层次
- 过渡融合区域：从肩部斜向延伸至髋部的斜线过渡带，人物身体在平面处逐渐溶解为像素粒子又凝聚为真人，数位笔触颗粒沿着身体轮廓飘散，主要分布在身体后方和侧面；贴附在屏幕上的画笔工具栏图标等UI元素被人物身体正确遮挡，少量随笔触颗粒一起飘散
- 完全 2D 区域：屏幕内的另一侧身体及腿部，是数位绘画风格的 2D 平面图像，有画笔笔触、图层透明度效果和数位板纹理，呈现明确的平面绘画质感，无体积感
- 过渡方式：人物侧身从平板屏幕中滑出坐起，身体在数位笔触溶解与凝聚中完成 2D→3D 的过渡，以屏幕玻璃为分界面形成破壁错觉

### 模板C：迈步走出全身 + 桌面场景
- 完全 3D 区域：头部、躯干、双臂及一条腿的大部分，已完全走出平板屏幕，前脚已经踩在真实的大理石桌面上，重心在前脚，身体微微前倾呈迈步动态，真实皮肤纹理、服装面料褶皱清晰分明
- 过渡融合区域：另一条腿的小腿和脚踝处与屏幕平面重合，有柔和的光晕、像素渐变和数位笔触效果；贴附在屏幕上的调色板、画笔、图层等绘画工具元素被人物身体正确遮挡；少量绘画工具元素从人物身后飘散飞出，分布在身体后方和侧面的半空；裙摆还带着淡淡的画笔笔触残留
- 完全 2D 区域：屏幕内的后脚及鞋履，是数位绘画风格的 2D 平面图像，有画笔笔触、图层透明度效果和数位板纹理，呈现明确的平面绘画质感，无体积感
- 过渡方式：人物从平板屏幕的数字绘画中迈步走出，一只脚已踩在现实的桌面上，身后飘散着绘画工具元素，身上带着数位笔触残留，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

### 模板D：伸手向前 + 笔触溶解
- 完全 3D 区域：一只手和前臂完全伸出屏幕，手指仿佛握着一支从屏幕里伸出来的触控笔（手中握着的触控笔为真实3D质感，自然挡在身前），手部有真实皮肤纹理和体积感，是画面的视觉焦点
- 过渡融合区域：手腕和前臂中部与屏幕表面重合处，有柔和的光晕、数位笔触渐变和像素溶解效果，手的周围有画笔笔触痕迹；贴附在屏幕表面的工具栏图标等UI元素被人物手臂正确遮挡；少量笔触粒子从过渡区域飘散，主要在手臂后方
- 完全 2D 区域：屏幕内的身体其余部分（头部、躯干、另一条手臂、双腿），是数位绘画风格的 2D 平面图像，有画笔笔触、图层透明度效果和数位板纹理，呈现明确的平面绘画质感，无体积感
- 过渡方式：人物的一只手臂穿过平板屏幕伸向观众，手和前臂为 3D 真人质感，身体其余部分仍在屏幕内为 2D 数字绘画，以屏幕玻璃为分界面形成 2D→3D 破壁错觉

## 默认主体气质
原创成年东方女性，20岁及以上，气质文艺清新，五官柔和精致，眼神慵懒迷茫，像刚从画中醒来还没回过神。

## 默认画幅
4:3 横版构图，超高清，高分辨率，细节清晰，生成1张独立图片，不要合并，不要拼图

## 场景与道具
浅色大理石桌面、平板电脑平放（无品牌标识）、触控笔斜放在旁边、咖啡杯、笔记本一角
屏幕内容：虚构的数位绘画作品、画笔工具栏图标、图层面板位、调色板图标（通用界面，不用真实软件名）
人物身体穿过屏幕平面，跪坐或侧身姿势
光线：柔和的室内自然光，屏幕轻微发光
光影：破壁人物在桌面和平板屏幕上投下真实柔和的阴影，增强真实感
