## 二、逐项设计

### #4：图片风格默认值

**现状：** 用户未指定图片风格时，必须弹出二选一（iPhone/单反），阻塞流程。

**改动：**
- 默认值：专业单反相机写真拍摄质感
- 用户未指定 → 自动使用默认，输出附带提示 `「默认使用单反写真质感，可随时改为 iPhone 直出质感」`
- 用户指定时 → 完全覆盖，行为不变

**改动文件：** `SKILL.md` — 默认值与覆盖规则 + 图片风格二选一

---

### #5：关键词命中跳过子路线选择

**现状：** 用户说"从手机里出来"→ 关键词唯一命中 phone-screen，但仍弹出"手机/电脑/平板"三选一。

**规则：**
- 用户输入的关键词在某大路线下唯一匹配一个子路线 → 直接锁定，跳过子路线选择
- 匹配多个子路线或无法确定 → 保持现有行为，返回子路线选项

**改动文件：** `SKILL.md` — 工作流步骤 5 + 分步交互规则

**场景对照：**

| 用户输入 | 路线 | 子路线匹配 | 行为 |
|----------|------|-----------|------|
| "从手机里出来" | screen | phone-screen（唯一） | 直接锁定 |
| "从屏幕里出来" | screen | 3 个匹配 | 返回三选一 |
| "从小红书里出来" | social-app | xiaohongshu（唯一） | 直接锁定 |
| "从社交App里出来" | social-app | 6 个匹配（模糊） | 返回六选一 |

### #11：一键生成快速模式

**触发条件：** 用户输入包含"破壁"关键词 + 明确的路线/媒介关键词 + 无额外定制需求（如"有创意""柔美""科技感"等）。

**行为：** 跳过所有交互步骤，直接使用默认值组装输出：

| 参数 | 默认值 |
|------|--------|
| 过渡类型 | 子路线默认模板 |
| 姿势 | 半身→lean-forward，全身→step-out |
| 图片风格 | 单反（#4 默认值） |
| 画幅 | 子路线默认画幅 |

**场景对照：**

| 用户输入 | 是否快速模式 | 锁定结果 |
|----------|------------|----------|
| "破壁，小红书，全身" | 是 | social-app/xiaohongshu + step-out + 默认模板 + 单反 |
| "破壁，油画，半身" | 是 | art-painting/oil-painting + lean-forward + 默认模板 + 单反 |
| "破壁，从手机里出来" | 是 | screen/phone-screen + lean-forward + 默认模板 + 单反 |
| "破壁，老照片，有创意" | 否（"有创意"是定制需求） | 正常流程 |

**改动文件：** `SKILL.md` — 工作流中插入快速模式检测步骤

### #9：反向破壁（3D→2D 吸入式）

**新增维度：** 破壁方向（正向/反向），不影响现有路线结构。

| 方向 | ID | 视觉描述 | 叙事感 |
|------|-----|---------|--------|
| 正向破壁 | `outward` | 人物从媒介中冲出/走出，2D→3D | 自由、突破、力量 |
| 反向破壁 | `inward` | 现实人物正在被吸入媒介，3D→2D | 迷失、穿越、悬念 |

**反向破壁视觉特征：**
- 上半身是 3D 真人，下半身正在像素化/油墨化/平面化，被一股力量拖入媒介
- 过渡区域是"媒介在吞噬人"——指尖、发梢、衣角已经开始变成 2D 平面影像
- 人物表情有挣扎/惊讶/迷离感，头发和衣物向媒介方向飘动
- 媒介边缘有向内吸拢的视觉引力感（漩涡、光线汇聚、碎片倒流）

**触发方式：** 用户说"反向破壁""被吸进去""被拉进去""从现实进入XX""反向"时触发。

**实现策略：**
- SKILL.md 增加破壁方向维度说明 + 反向破壁视觉指南（约 15 行）
- 可选变化参数增加"破壁方向：正向 / 反向"
- 首批子路线增加反向模板：phone-screen、xiaohongshu、oil-painting（3 个热门路线）
- 其余子路线后续逐步补充

**改动文件：** `SKILL.md` + 3 个子路线文件

### #10：AI 生成界面子路线

**新增子路线：** `routes/digital-ui/ai-generation.md`

| 属性 | 内容 |
|------|------|
| 大路线 | digital-ui（数字界面成真） |
| 子路线 ID | `ai-generation` |
| 中文名 | AI 生成界面 |
| 触发关键词 | AI生成、AI绘画、正在生成、生成中、从AI里出来、AI界面、生成界面 |
| 视觉指纹 | AI 图像生成工具的界面，画面中央是一张正在生成的人物图像，从模糊噪声到清晰写真，人物从生成进度中破壁而出 |
| 默认姿势 | 半身→lean-forward，全身→step-out |
| 默认画幅 | 3:4 竖版 |
| 默认主体 | 原创成年东方女性，20岁及以上，气质知性现代，眼神带着从数字世界诞生的好奇 |

**界面元素：** 生成进度条（50%-100%）、提示词输入框（抽象色块）、分辨率选择（4K/8K 标签）、风格标签（写实/摄影/电影感）、种子数值位、生成按钮（发光高亮）

**过渡模板库（4 种）：**

- **模板A（默认）：像素溶解 + 俯身探出头** — 人物上半身从生成预览区中探出，下半身还在像素溶解/噪声中，进度条接近 100%，界面上风格标签和种子数值闪烁
- **模板B：波动涟漪 + 全身走出** — 人物从 AI 界面中迈步走出，脚踩在真实桌面，界面像水面产生涟漪，提示词文字在涟漪中扭曲，裙摆带着像素噪声
- **模板C：碎裂飞溅 + 仰身冲出** — AI 界面碎裂成玻璃片飞溅，人物从碎片缺口中冲出，碎片中倒映着不同阶段的生成预览（噪声→模糊→清晰）
- **模板D：伸手向前 + 生成中** — 一只手从 AI 界面中伸出，手指已完全真实，手背还带着像素马赛克，界面显示"生成中 78%"

**元叙事：** "我正在生成我自己"——人物从生成她的 AI 界面中破壁，有强烈的自指涉趣味。

**改动文件：** 新建 `routes/digital-ui/ai-generation.md` + 修改 `routes/digital-ui/_registry.md` + 修改 `SKILL.md` 路线总览表
